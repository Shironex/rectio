## Install

```sh
pnpm dlx @rectio/cli add docs-code-tabs
```

The motion variant is `motion-docs-code-tabs`. It installs the plain block too and changes only how the block moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

One example in several forms (two languages, two files) and an install block for npm, pnpm, yarn and bun. Both remember the reader's pick, and every set with the same key moves together. In the motion variant the indicator glides between tabs.

## Usage

Give `CodeTabs` a list of tabs, each with a `label` and its `code` or `tokens`. A shared `storageKey` such as `"language"` keeps every TypeScript and JavaScript pair on the site on the same tab. `InstallTabs` takes the command in npm's words, such as `npm install @halyard/core` or `npx halyard init`, and writes the other managers' commands from it.

## Accessibility

- The tabs are a real tab list: arrow keys move between them and the panel is labelled by its tab.
- The remembered choice is read after the first render, so the page never mismatches its server HTML.
