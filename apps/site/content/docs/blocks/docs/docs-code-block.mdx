## Install

```sh
pnpm dlx @rectio/cli add docs-code-block
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

A code block with a file name, line highlights, line numbers, diff marks and a copy button. The syntax colours are token driven: the block takes `tokens`, one array per line, from any build-time highlighter, and colours them through CSS variables such as `var(--rx-code-token-keyword)`. Without tokens it shows plain `code` in the foreground colour.

## Usage

Highlight on the server so no highlighter ships to the browser. With shiki, a CSS variables theme with the `--rx-code-` prefix reads the theme's colours:

```ts
import { createCssVariablesTheme, createHighlighter } from 'shiki';

const theme = createCssVariablesTheme({ variablePrefix: '--rx-code-' });
const highlighter = await createHighlighter({ themes: [theme], langs: ['ts', 'sh'] });
const { tokens } = highlighter.codeToTokens(code, { lang: 'ts', theme });
```

Pass `tokens` (and `code` for copying). A Markdown fence's meta string works too: `meta='title="queue.ts" {2,5} showLineNumbers'` sets the title, the highlighted lines and the numbers, and explicit props win. Lines that start with `+` or `-` are drawn as added and removed in a `diff` block, or anywhere with `diff`.

## Accessibility

- Added and removed lines carry a sign and a hidden word, never colour alone.
- Every token colour holds 4.5:1 against the code background in both themes.
- The copy button announces that it copied.
