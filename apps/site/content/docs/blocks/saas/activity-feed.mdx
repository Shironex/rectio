## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add activity-feed
```

The motion variant is `motion-activity-feed`. It installs the plain block too; new events arrive in place.

## Usage

Pass the events in any order; the block sorts them newest first and groups them under Today,
Yesterday or their date. Each event is a sentence: the actor, a past tense `verb` and an optional
`target`, with a `detail` underneath (comments show it as a quote). The `kind` picks the small icon
on the avatar and the filter it belongs to.

`filterable` adds a filter row of comments, changes, people and account, leaving out filters with
nothing in them. For older pages, pass `hasMore`, `onLoadMore` and `loadingMore`.

## Logic

`groupActivityByDay`, `activityMatches` and `activityFilterCounts` are exported and tested on
their own.

## Accessibility

- Each day is a labelled region with its own heading, and each event a list item that reads as a sentence.
- Times are `<time>` elements with the exact moment, shown on hover and read out after the relative time.
- Kind icons are decoration; the verb carries the meaning.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
