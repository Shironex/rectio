## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add docs-prose
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

Long-form text in the theme's type and the components a page needs beyond Markdown: headings with a link to themselves, callouts, numbered steps, a file tree, tables that scroll inside their own frame and figures with a caption.

## Usage

Wrap a rendered page in `DocsProse`. `docsMdxComponents` maps Markdown headings, tables, links and fences to these blocks and adds the components a page can write directly, so it works with any MDX setup:

```tsx
import { DocsProse, docsMdxComponents } from '@rectio/blocks/docs';

<DocsProse>
  <Content components={docsMdxComponents} />
</DocsProse>;
```

The map covers `Callout`, `Steps`, `Step`, `FileTree`, `Figure`, `Badge`, `Kbd`, `CodeBlock`, `CodeTabs`, `InstallTabs`, `PropsTable`, `SignatureCard`, `Endpoint` and `LinkCards`. A plain Markdown fence is drawn as a `CodeBlock` without highlighting; pass your own `pre` that supplies tokens to colour it.

## Accessibility

- A callout is a note landmark and names its kind in words, so the tint is never the only signal.
- Steps are an ordered list and each title says its number for screen readers.
- A wide table scrolls inside a focusable, named region, so it scrolls with the keyboard and the page does not.
- Folders in a file tree are buttons that say whether they are expanded.
