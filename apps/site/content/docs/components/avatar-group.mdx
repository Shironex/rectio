## Install

```sh
pnpm dlx rectio add avatar-group
```

## Usage

```tsx
import { AvatarGroup } from '@/components/ui/avatar-group';

<AvatarGroup
  label="Approvers"
  items={[{ name: 'Ana Ruiz' }, { name: 'Tomasz Nowak' }, { name: 'Lena Fischer' }]}
  max={4}
/>;
```

Past `max`, the rest fold into a `+N` chip whose accessible name lists who it hides. A single extra
person is never folded into `+1`, which would take the same room as their avatar.

The names show under the group on hover and on keyboard focus, without a tooltip: the stack fans out
a little (transform only, so nothing around it moves) and the list of names fades in. Set
`names="always"` to keep the names visible, or `"none"` to leave them to assistive technology.
`spacing="spaced"` sets avatars side by side instead of overlapping.

## Accessibility

- A group named by `label`, holding one named image per person and the `+N` chip.
- With `names="hover"` the group takes keyboard focus, so the names are reachable without a pointer.
- The fan-out is a transform and stops under reduced motion.
