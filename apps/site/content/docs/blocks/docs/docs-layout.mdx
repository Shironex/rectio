## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add docs-layout
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

The frame of a docs site: the header across the top, the navigation down the start edge, the page at a reading measure and the table of contents down the end edge. Each column stays in view while the page scrolls, and a skip link jumps straight to the content. The preview is a full page frame in a short, scrolling box.

## Usage

Pass the header, sidebar and table of contents as nodes, usually `DocsHeader`, `DocsSidebar` and `DocsToc`. Below the large breakpoint the sidebar is hidden; give `DocsHeader` a `mobileNav` and a menu button opens it in a sheet. Use `top` for a breadcrumb, `bottom` for the edit link, feedback and pager, and `footer` for a full width footer. Set `wide` for a home page or a changelog that has no table of contents.

## Accessibility

- A skip link is the first thing a keyboard reader reaches and it jumps to the content.
- The header, navigation, main content and table of contents are separate landmarks.
- The phone menu opens in a sheet and closes after a link press.
