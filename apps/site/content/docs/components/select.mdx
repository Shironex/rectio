## Install

```sh
pnpm dlx rectio add select
```

`field` and `theme-scope` install with it.

## Usage

```tsx
import { Field, FieldLabel } from '@/components/ui/field';
import { Select, SelectContent, SelectItem, SelectTrigger } from '@/components/ui/select';

const items = [
  { value: 'flights', label: 'Flights' },
  { value: 'rail', label: 'Rail' },
];

<Field>
  <FieldLabel>Category</FieldLabel>
  <Select items={items} value={category} onValueChange={setCategory}>
    <SelectTrigger placeholder="Choose a category" />
    <SelectContent>
      <SelectItem value="flights" hint="6110">
        Flights
      </SelectItem>
      <SelectItem value="rail" hint="6120">
        Rail
      </SelectItem>
    </SelectContent>
  </Select>
</Field>;
```

Pass `items` to `Select` so the trigger can show the label of the chosen value before the list has
opened. Group long lists with `SelectGroup`. The list opens below the trigger; set
`alignItemWithTrigger` to open it over the selected item instead.

The popup portals into the nearest `ThemeScope`, so it keeps that scope's theme and mode.

The motion variant opens the list with a spring from the trigger and glides the highlight between
items under the pointer; arrow keys move it at once. Use its `SelectItem` with its `SelectContent`.

## Props

### Select

`Select` is Base UI's `Select.Root`: `items`, `value`, `defaultValue`, `onValueChange`, `multiple`,
`disabled`, `name` and the rest.

### SelectTrigger

Every prop of Base UI's `Select.Trigger` is accepted as well.

Every prop of Base UI's `Select.Popup` is accepted as well.

## Accessibility

- The trigger is named by its `FieldLabel` and shows the placeholder until a value is chosen.
- Arrow Down on the trigger opens the list; the arrows move through it and Enter picks.
- Escape closes the list and returns focus to the trigger.
- The chosen item carries a check mark as well as a heavier weight.
