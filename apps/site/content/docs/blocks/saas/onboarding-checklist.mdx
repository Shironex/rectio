## Install

```sh
pnpm dlx @rectio/cli add onboarding-checklist
```

The motion variant is `motion-onboarding-checklist`. It installs the plain block too; the block enters once, on first view.

## Usage

Pass the steps in the order they should be done, each with whether it is done. The first step not
done becomes the current one: it is raised, labelled Next, and its action is the primary button. Give a
step an `action` with `onSelect` or `href` to do it from the list; pass `onToggleStep` to offer
"Mark as done" and its undo, in a small menu on each row, for steps your app cannot detect by
itself.

Once every step is done the list gives way to a finished note, with Hide when you pass
`onDismiss`. The block holds only whether it is folded; `defaultCollapsed` starts it folded to the
progress bar.

## Logic

`onboardingProgress` returns the count, the percent, the next step and whether the list is
complete; `onboardingSummary` says it in words.

## Accessibility

- The current step carries `aria-current="step"`; every step says whether it is done in words, not only with a tick.
- The count is said once, in the description, and announced politely as it changes; the bar under it is a labelled meter with the same words.
- The fold button reports `aria-expanded` and names what it shows or hides.
- Works in light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
