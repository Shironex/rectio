## Install

```sh
pnpm dlx @rectio/cli add invoice-list
```

The motion variant is `motion-invoice-list`. It installs the plain block too and changes only how the
block enters.

## Usage

Overdue is read from the due date, never stored: an invoice due today is due, not late. Part
payments show what is still owed and the original total under it. The footer sums what is owed on
sent invoices and says how many void invoices it left out.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source is in
the repository, under `packages/blocks`.

## Messages

Every word the block prints, including what screen readers hear, comes from `messages`. The full
English defaults are exported as `INVOICE_LIST_MESSAGES`, typed as `InvoiceListMessages`. Pass only the keys you
change; a message that counts or names a figure is a small function, so a language can order the
words and choose its plural form with `plural()`.

```tsx
import { plural } from '@rectio/blocks';

const invoices = (count: number) => plural(count, { one: 'invoice', other: 'invoices' }, 'en-GB');

<InvoiceList
  invoices={rows}
  currency="GBP"
  locale="en-GB"
  messages={{
    title: 'Sales invoices',
    newInvoice: 'Create invoice',
    description: (period, count) => `${period}, ${count} ${invoices(count)}`,
    dueText: (due) => (due.kind === 'today' ? 'Due today' : `Due in ${due.days} days`),
  }}
/>;
```

A complete set typed as `InvoiceListMessages` fails to compile when a key is missing.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`invoiceState`, `balanceDue`, `invoiceTotals`, `periodRange` and `matchesFilter`.

## Accessibility

- Built on DataTable: sortable headers, and a Sort by control on narrow widths where headers hide.
- Every state is a word with an icon, never a colour alone; void amounts are struck through and named.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
