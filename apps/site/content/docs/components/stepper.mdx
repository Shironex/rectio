## Install

```sh
pnpm dlx @rectio/cli add stepper
```

## Usage

```tsx
import { Stepper } from '@/components/ui/stepper';

<Stepper
  label="Account setup"
  current={2}
  steps={[
    { title: 'Company' },
    { title: 'Bank account' },
    { title: 'Tax settings', description: 'VAT number and rates' },
    { title: 'Invite team' },
  ]}
  onStepSelect={goToStep}
/>;
```

Steps before `current` are complete, after it upcoming. A step can override its status, such as
`error` for a step that needs attention. With `onStepSelect`, completed steps become buttons that go
back; upcoming steps stay text, so the order of the flow holds.

On a narrow row the horizontal stepper keeps only the current step's title; vertical steps carry
descriptions comfortably.

Every prop of an `ol` is accepted as well.

## Accessibility

- An ordered list; the current step has `aria-current="step"`.
- Each step says its status in words: completed, current step, not started, needs attention.
- Titles hidden on a narrow row stay readable to assistive technology.
