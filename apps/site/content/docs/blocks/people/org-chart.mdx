## Install

```sh
pnpm dlx @rectio/cli add org-chart
```

The motion variant is `motion-org-chart`. It installs the plain block too.

## Usage

```tsx
import { OrgChart } from '@/components/blocks/people/org-chart/org-chart';

<OrgChart
  people={[
    { id: 'dana', name: 'Dana Whitfield', title: 'Chief Executive' },
    { id: 'ines', name: 'Ines Carvalho', title: 'Engineer', managerId: 'dana' },
  ]}
  personHref={(person) => `/people/${person.id}`}
/>;
```

Pass people as a flat list, each naming their manager. The tree is built once in linear time and
only open branches are drawn, so an organisation of thousands opens at once. A manager missing
from the list, or a loop of managers, never hides anyone: those people show at the top.

Search matches names first, then titles and departments, ignoring accents. Picking a result opens
every branch above that person, selects them and moves the focus to them. The panel beside the
tree shows the picked person, their manager and their direct reports. Links go through the
LinkProvider, so they use your router.

On a phone the tree becomes a list: a person and their reports, a row for each report that opens
their team, and a button back up to the manager.

## Logic

`buildOrg(people)` gives the roots, the reports by manager and every team size; `managerChain`
lists the managers above someone and `searchOrg(model, query, limit)` ranks matches (eight by
default; pass `Infinity` to count them all). They run on the
server too.

## Accessibility

- The tree is a tree view: arrows move, Right opens a branch, Left closes it or goes to the
  manager, Home and End jump. Each row says the person's title and team size.
- The search results are buttons the arrows move through, and how many match in all is said once
  typing settles, with how many are listed when that is fewer.
- The phone list's buttons say whose team they open and how big it is, and the move is announced.
