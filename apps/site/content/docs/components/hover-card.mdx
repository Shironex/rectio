## Install

```sh
pnpm dlx @rectio/cli add hover-card
```

`popover`, `select` and `theme-scope` install with it.

## Usage

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from '@/components/ui/hover-card';

<HoverCard>
  <HoverCardTrigger href="/customers/kowalski-sons">
    Kowalski &amp; Sons sp. z o.o.
  </HoverCardTrigger>
  <HoverCardContent>{/* a short summary */}</HoverCardContent>
</HoverCard>;
```

The trigger is an ordinary link, so touch and keyboard users still reach the page. The card only
adds a glance, after a 500ms delay on hover. Keep it to a summary: anything to act on belongs on the
page the link opens, because the card cannot be reached on a touch screen.

The motion variant grows the card from the link. Import `HoverCardContent` from
`@rectio/motion/navigation`.

## Props

### HoverCard

Base UI's `PreviewCard.Root`.

### HoverCardTrigger

Every prop of Base UI's `PreviewCard.Trigger` is accepted, including `href`, as well.

<TypeTable
  type={{
    delay: {

    closeDelay: {
      type: 'number',

/>

### HoverCardContent

Every prop of Base UI's `PreviewCard.Popup` is accepted as well.

<TypeTable
  type={{

    },
    align: { type: "'start' | 'center' | 'end'", default: "'start'" },
    sideOffset: { type: 'number', default: '8' },
  }}
/>

## Accessibility

- The trigger is a real link with a visible focus ring; the page it opens has all the information.
- The card also opens when the link takes keyboard focus, and Escape closes it.
- It is never the only place a fact appears: touch screens do not open it.
