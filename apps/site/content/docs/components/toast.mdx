## Install

```sh
pnpm dlx rectio add toast
```

`theme-scope` installs with it.

## Usage

Put `ToastProvider` once near the root, inside your `ThemeScope`, then add toasts from any component
below it.

```tsx
import { ToastProvider, useToast } from '@/components/ui/toast';

<ThemeScope>
  <ToastProvider timeout={8000}>
    <App />
  </ToastProvider>
</ThemeScope>;

function RemoveLine({ expense }: { expense: Expense }) {
  const toast = useToast();
  return (
    <Button
      variant="danger"
      onClick={() => {
        remove(expense);
        const id = toast.add({
          type: 'success',
          title: 'Expense removed',
          description: 'Total now €1,179.30.',
          actionProps: {
            children: 'Undo',
            onClick: () => {
              restore(expense);
              toast.close(id);
            },
          },
        });
      }}
    >
      Remove
    </Button>
  );
}
```

`type` is `success`, `error` or `info`; each carries its own icon. Write the outcome in the title, so
the kind is clear without the icon's colour. Close the toast yourself in the action's `onClick`.

Toasts stack in the corner of the nearest `ThemeScope`, newest nearest the corner. They close after
`timeout`; hovering or focusing the stack pauses it. A toast with an action needs more time, about
8000 ms, so the action can still be reached from the keyboard. They can be swiped away right or down.

### useToast

`useToast` is Base UI's `Toast.useToastManager`. `add(options)` returns the toast's id; `update(id,
options)` and `close(id)` change or close it, and `promise` follows a promise through loading,
success and error.

## Accessibility

- Toasts are announced to screen readers: politely by default, urgently with `priority: 'high'`.
- F6 moves focus into the stack and back.
- Each toast has a named close button, and the action is drawn as a bordered button so it reads as
  a control.
- Every kind carries an icon and words, never colour alone.
- Under reduced motion a toast fades in place instead of rising.
