## Install

```sh
pnpm dlx @rectio/cli add logo-strip
```

The motion variant is `motion-logo-strip`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

The companies that use the product, logos only: no captions, no categories. It sits directly under
the hero.

## Usage

Give each logo a `name` and, if you have one, an SVG or image in `currentColor` so it follows the
theme. Without a logo the name is set as a wordmark. Use at most one moving strip per page.

## Accessibility

- Logos take the muted text colour, so every brand reads at the same weight in both modes.
- The static row is a list; the marquee is labelled "Customer logos" and pauses on hover and focus.
- Under reduced motion the marquee holds still.
