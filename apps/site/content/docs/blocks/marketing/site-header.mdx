## Install

```sh
pnpm dlx @rectio/cli add site-header
```

This block has no motion variant: nothing on it moves.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

The bar at the top of every page: your brand, one line of links and the main action, with the links
folded into a menu on narrow screens.

## Usage

Pass the brand as any node and name its link with `brandLabel`. Mark the current page with
`currentHref` and its link gets `aria-current="page"`. The bar sticks to the top of the viewport
unless you set `sticky={false}`.

## Accessibility

- Below the `md` breakpoint the links open as a sheet under the bar. It traps focus, closes on Escape or a link press and returns focus to its button.
- The current page is marked with `aria-current="page"`, not only with colour.
- Every link and button keeps a visible focus ring.
- Links render through the kit's `Anchor`, so a [`LinkProvider`](/docs/components/link) sends them
  through your router.
