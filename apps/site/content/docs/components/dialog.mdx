## Install

```sh
pnpm dlx rectio add dialog
```

`theme-scope` installs with it.

## Usage

```tsx
import { Button } from '@/components/ui/button';
import {
  Dialog,
  DialogBody,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog';

<Dialog>
  <DialogTrigger render={<Button />}>Add expense</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Add expense</DialogTitle>
      <DialogDescription>Goes into the March report as a draft line.</DialogDescription>
    </DialogHeader>
    <DialogBody>{/* fields */}</DialogBody>
    <DialogFooter>
      <DialogClose render={<Button variant="ghost" />}>Cancel</DialogClose>
      <Button type="submit">Save expense</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>;
```

`DialogContent` holds the backdrop, the viewport and the popup. The popup sits near the top of the
screen, so it grows downward when errors appear instead of moving under the pointer. The footer
puts actions at the end; the primary action goes last.

The dialog portals into the nearest `ThemeScope`, so it keeps that scope's theme and mode.

The motion variant opens the popup in the centre, growing from just under full size on a short
spring, and closes it faster on a tween. Its `Dialog` and `DialogTrigger` are the plain ones, exported
again so one import path covers the dialog; the other parts are the plain ones too.

## Props

### Dialog, DialogTrigger, DialogClose

These are Base UI's `Dialog.Root`, `Dialog.Trigger` and `Dialog.Close`. `Dialog` takes `open`,
`defaultOpen`, `onOpenChange` and `modal`; the trigger and close take `render` to draw a `Button`.

### DialogContent

Every prop of Base UI's `Dialog.Popup` is accepted as well.

    },

/>

### DialogTitle, DialogDescription

Every prop of Base UI's `Dialog.Title` and `Dialog.Description`.

### DialogHeader, DialogBody, DialogFooter

Plain `div` elements with the dialog's spacing; every `div` prop is accepted.

## Accessibility

- Opens as a modal dialog named by `DialogTitle` and described by `DialogDescription`.
- Focus moves into the dialog, stays there while it is open, and returns to the trigger on close.
- The rest of the page is hidden from assistive technology while it is open.
- Escape and a press on the backdrop close it. The corner close button is named by `closeLabel`.
