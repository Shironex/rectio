```sh
pnpm dlx @rectio/cli add tree
```

`scroll-area` installs with it.

## Usage

```tsx
import { Tree, type TreeNode } from '@/components/ui/tree';

const ACCOUNTS: TreeNode[] = [
  {
    id: 'assets',
    label: 'Assets',
    children: [
      { id: 'bank', label: 'Bank accounts' },
      { id: 'receivables', label: 'Receivables' },
    ],
  },
  { id: 'archive', label: 'Archive', hasChildren: true },
];

<Tree
  aria-label="Chart of accounts"
  items={ACCOUNTS}
  defaultExpanded={['assets']}
  selected={selected}
  onSelectedChange={setSelected}
  loadChildren={(node) => fetchChildren(node.id)}
  className="h-80"
/>;
```

Use a tree for a hierarchy the user browses: folders, a chart of accounts, an org's teams. For a
flat list with groups, a list or a table reads faster.

`items` is a nested list of nodes with unique ids. A node can carry an `icon` and a `meta` drawn
at the end of the row, such as a count. `expanded` and `selected` are arrays of ids, controlled
or uncontrolled. `selectionMode` is `single` by default; `multiple` lets Space and a Ctrl or Cmd
press toggle rows and Shift with an arrow extend; `none` makes a press open and close. Enter or a
double click calls `onAction`, such as opening a file. A press on the chevron opens and closes
without changing the selection.

A node with `hasChildren` and no `children` loads them through `loadChildren` the first time it
opens; its chevron turns into a spinner meanwhile. A failed load shows a row that tries again on
Enter or a press. The tree keeps what it loaded; to refresh a branch yourself, make a loader with
`useTreeChildren(load)`, pass it as `loader`, and call `loader.reload(node)`.

Give the tree a height through `className`: it scrolls in its own area.

## Accessibility

- `role="tree"` with `treeitem` rows carrying their level, position and set size, `aria-expanded`
  on branches, `aria-selected` when rows can be chosen and `aria-busy` while a branch loads.
- One Tab stop: the focused row, else the first chosen row, else the first row.
- Down and Up move; Right opens a branch, then steps into it; Left closes it, then steps out to
  the parent; Home and End jump; `*` opens every branch at the level; typing jumps to a matching
  name.
- Enter acts, Space selects; in multiple mode Shift with an arrow extends and Ctrl or Cmd with A
  selects every visible row.
- Rows grow to 44px on touch screens.
