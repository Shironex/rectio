## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add invoice-list
```

The motion variant is `motion-invoice-list`. It installs the plain block too and changes only how the
block enters.

## Usage

Overdue is read from the due date, never stored: an invoice due today is due, not late. Part
payments show what is still owed and the original total under it. The footer sums what is owed on
sent invoices and says how many void invoices it left out.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source comes with the license.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`invoiceState`, `balanceDue`, `invoiceTotals`, `periodRange` and `matchesFilter`.

## Accessibility

- Built on DataTable: sortable headers, and a Sort by control on narrow widths where headers hide.
- Every state is a word with an icon, never a colour alone; void amounts are struck through and named.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
