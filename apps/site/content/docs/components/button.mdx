## Install

```sh
pnpm dlx @rectio/cli add button
```

## Usage

```tsx
import { Button } from '@/components/ui/button';

<Button onClick={approve}>Approve report</Button>;
```

One primary action per view. `danger` is outlined until hovered or pressed, so a destructive action
never outweighs the primary beside it. `loading` shows a spinner beside the label, which stays
readable, keeps the focus, blocks presses and sets `aria-busy`. A leading icon gives its slot to
the spinner, so the button keeps its exact width; a text-only button grows by the spinner. Under
reduced motion the spinner breathes in place instead of turning.

To make a link look like a button, render it as one: `<Button render={<Link href="/billing" />}>`.
A link keeps its link role and gets no `type`; `nativeButton` is inferred from `render`, so set it
yourself only for a render function.

## Accessibility

- A native `<button>`: Enter and Space press it, and it is in the tab order.
- On touch screens every size grows to a 44px target. Space small buttons in a row with
  `pointer-coarse:gap-touch-gap`, so their hit areas stay apart at every density and skin.
- An `iconOnly` button needs an `aria-label`; the icon is hidden from assistive technology.
