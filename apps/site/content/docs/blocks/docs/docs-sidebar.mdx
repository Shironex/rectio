## Install

```sh
pnpm dlx @rectio/cli add docs-sidebar
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

The navigation tree: titled sections, pages that hold other pages, badges such as New and Beta, and the current page marked. The groups on the way to the current page start open.

## Usage

Describe the tree as data: sections of items, each with a `title`, an optional `href`, a `badge` and nested `items`. An item without an `href` is a group that only holds pages. Pass the current path as `currentHref`. Set `external` on a link that leaves the docs. In a sheet, `onNavigate` closes it after a link press; `DocsHeader` does this for you through `mobileNav`.

## Accessibility

- The tree is a navigation landmark.
- The current page has `aria-current="page"`.
