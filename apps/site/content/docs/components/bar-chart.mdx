## Install

```sh
pnpm dlx @rectio/cli add bar-chart
```

## Usage

```tsx
import { BarChart } from '@/components/ui/bar-chart';

<BarChart
  data={months}
  category="month"
  stacked
  series={[
    { key: 'starter', label: 'Starter' },
    { key: 'team', label: 'Team' },
  ]}
  format="currency"
  currency="EUR"
/>;
<BarChart
  data={tickets}
  category="team"
  orientation="horizontal"
  labels
  series={[{ key: 'open', label: 'Open' }]}
/>;
```

`data` is your own rows; `category` names the field on the category axis and each series names a
numeric field. Several series sit side by side, or one on another with `stacked`, where only the top
segment is rounded and the tooltip adds the total. Bars below zero hang from a zero line.

Use `horizontal` for long category names or a ranking: the plot grows with the number of rows.
`labels` writes each bar's figure (the total for a stack) at its end.

The motion variant grows the bars from the zero line one after another on first view.

## Accessibility

- A figure with a summary read before the plot: the range, and for each series its total, highest and lowest category. Pass `summary` to say it in your own words.
- Every chart has a table twin, in the page for screen readers and shown on request with **Show
  table**. The legend and the table use the same names and figures as the tooltip.
- The plot takes focus: arrow keys move from point to point, and the tooltip follows.
- Colours come from the three chart series tokens, which stay apart for every common colour vision
  type; series past the third repeat a colour and turn dashed, so a line never rests on colour alone.
- Figures use the true minus sign, so signed values line up.
