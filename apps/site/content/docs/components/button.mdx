## Install

```sh
pnpm dlx rectio add button
```

## Usage

```tsx
import { Button } from '@/components/ui/button';

<Button onClick={approve}>Approve report</Button>;
```

One primary action per view. `danger` is outlined until hovered or pressed, so a destructive action
never outweighs the primary beside it. `loading` keeps the label's width and the focus, blocks
presses and sets `aria-busy`.

## Props

Every prop of Base UI's `Button` is accepted as well.

## Accessibility

- A native `<button>`: Enter and Space press it, and it is in the tab order.
- On touch screens every size grows to a 44px target.
- An `iconOnly` button needs an `aria-label`; the icon is hidden from assistive technology.
