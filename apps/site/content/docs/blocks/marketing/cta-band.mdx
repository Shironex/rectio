## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add cta-band
```

The motion variant is `motion-cta-band`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

The closing ask: one line, one sentence, one primary action.

## Usage

`accent` fills the band with the accent colour, the loudest moment on the page; use `tinted` on a
page that already has one loud section. `centered` stacks everything and `split` puts the actions
beside the copy on wide screens.

## Accessibility

- The band is a section named by its headline.
- Actions are links: they go somewhere, with a visible focus ring.
