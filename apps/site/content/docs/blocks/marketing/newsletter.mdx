## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add newsletter
```

The motion variant is `motion-newsletter`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

An email signup. The address is checked before it is sent, the button holds its place while
sending, an error reads under the field, and success replaces the form with a status message that
assistive technology announces.

## Usage

The block holds no list and sends nothing itself. Pass `onSubscribe`: resolve when the address is
saved, or throw an `Error` to show its message under the field. Use `layout="compact"` in a footer
column or a sidebar.

## Accessibility

- The field has a real label, and its error reads under it.
- The form sits in a polite live region, so the success message is announced when it appears.
- The check is light: the real check is the confirmation email.
