## Install

```sh
pnpm dlx rectio add announcement-bar
```

This block has no motion variant: nothing on it moves.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

A thin bar above the header for one piece of news: a release, an event, a changelog entry.

## Usage

Pass `onDismiss` to show a close button, and remember the dismissal yourself, by announcement id.
`accent` fills the bar with the accent colour; `subtle` tints it softly.

## Accessibility

- On narrow screens the whole line is the link; the close button sits apart from it.
- The close button is separate from the link, so each does one thing.
