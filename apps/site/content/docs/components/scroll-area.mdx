## Install

```sh
pnpm dlx rectio add scroll-area
```

## Usage

```tsx
import { ScrollArea } from '@/components/ui/scroll-area';

<ScrollArea label="Recent receipts" className="h-56">
  {/* a long list */}
</ScrollArea>;
```

Native scrolling underneath: wheel, touch, keyboard and find in page all work. The scrollbar is thin
and appears while scrolling or under the pointer. Edges fade where more content waits, so it is clear
the area scrolls; turn that off with `fade={false}`. Give the area a height.

## Props

Every prop of Base UI's `ScrollArea.Root` is accepted as well.

## Accessibility

- The viewport takes keyboard focus with a visible ring, so it scrolls from the keyboard.
- With `label` it is a named region.
