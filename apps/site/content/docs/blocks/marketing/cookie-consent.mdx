## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add cookie-consent
```

The motion variant is `motion-cookie-consent`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

A cookie banner that asks before anything optional runs: accept all and reject all at the same
weight, one press each, and a way to choose per category.

## Consent is your responsibility

The block records a decision; it does not make your site compliant. List every category you really
use, load optional scripts only when `isAllowed` says so, keep the saved record as proof, and bump
`version` when your cookie list changes so visitors are asked again. Your cookie policy text is
yours to write: the legal page templates are a starting point and are not legal advice.

## Usage

On phones (below the `sm` breakpoint) the banner is a short strip: the title, a one-line
`shortDescription` and one row with Manage, Reject all and Accept all, reject and accept at equal
weight. The full description shows from `sm` up. The button that opens the per-category dialog is
labelled "Manage cookies" (it reads "Manage" on a phone, with the full name as its accessible name).

Keep the saved decision in your own storage (`loadConsent` and `saveConsent` read and write
`localStorage` safely) and pass it back as `consent`. While it covers `version`, the banner stays
away. Open `CookiePreferences` from a "Cookie settings" link in the footer so visitors can change
their mind.

## Logic

Decisions are plain data, so a server can read them: `acceptAll`, `rejectAll`, `chooseConsent`,
`initialChoices`, `hasDecided`, `isAllowed`, `loadConsent` and `saveConsent`.

## Accessibility

- The banner is a labelled region, not a modal: the page stays usable while it waits.
- Accept all and reject all have the same weight and take one press each.
- Preferences use real switches with labels; required categories show as always on.
- Focus moves into the preferences dialog and returns to what opened it.
