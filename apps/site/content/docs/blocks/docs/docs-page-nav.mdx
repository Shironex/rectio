## Install

```sh
pnpm dlx @rectio/cli add docs-page-nav
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

What sits around a page: a breadcrumb from the docs home to the current page, a row with an edit link and the date of the last change, and the previous and next page.

## Usage

Work out the previous and next page from your navigation with `pagerFor(sections, currentHref)`, and the trail for the breadcrumb with `trailTo`. `DocsPageMeta` takes the page's edit URL and an ISO date, and its children land at the end of the row, a fine place for `DocsFeedback`. Links go through the same `DocsLink` as every docs block, so your router's link component applies.

## Accessibility

- The pager and the breadcrumb are navigation landmarks with their own names.
- The current breadcrumb item is marked with `aria-current="page"`.
- The pager is a navigation landmark with its own name.
