## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add cash-flow
```

The motion variant is `motion-cash-flow`. It installs the plain block too and changes only how the
block enters.

## Usage

Inflow bars rise and outflow bars fall from one zero line, and net runs across them as a line
with a halo, so it reads over either series. Quarters are summed in minor units from the months,
so a quarter always equals its three months to the cent.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source comes with the license.

## Messages

Every word the block prints, including what screen readers hear, comes from `messages`. The full
English defaults are exported as `CASH_FLOW_MESSAGES`, typed as `CashFlowMessages`. Pass only the keys you
change; a message that counts or names a figure is a small function, so a language can order the
words and choose its plural form with `plural()`.

```tsx
<CashFlowChart
  points={points}
  currency="PLN"
  locale="pl-PL"
  messages={{
    title: 'Przepływy pieniężne',
    monthly: 'Miesiące',
    quarterly: 'Kwartały',
    quarter: (quarter, year) => `${['I', 'II', 'III', 'IV'][quarter - 1]} kw. ${year}`,
    positiveNote: (positive, total) => `Dodatnie w ${positive} z ${total} okresów`,
  }}
/>
```

A complete set typed as `CashFlowMessages` fails to compile when a key is missing.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`aggregateCashFlow(points, granularity, currency)` and `summarizeCashFlow(periods, currency)`.

## Accessibility

- Tab to the plot and step through the periods with the arrow keys: the tooltip follows the focus.
- Show table reveals the same figures as a table; it is always in the page for screen readers.
- Series colours hold 3:1 against the surface and stay apart under protan, deutan and tritan vision; outflow also carries a minus sign.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
