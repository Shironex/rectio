## Install

```sh
pnpm dlx rectio add skeleton
```

## Usage

```tsx
import { SkeletonCard, SkeletonLine, SkeletonText } from '@/components/ui/skeleton';

<SkeletonText heading lines={3} label="Loading the note" />;
<SkeletonLine width="1/2" size="sm" />;
```

Reach for a skeleton when the shape of the result is known: it keeps the layout still when the
content lands. Size each shape like the content it stands in for.

The primitives are `Skeleton` (a block), `SkeletonLine` (a line of text at a type size) and
`SkeletonCircle`. The presets compose them: `SkeletonText`, `SkeletonCard`, `SkeletonTable` (with a
right-aligned figure column), `SkeletonListItem` and `SkeletonChart` (bars or a line, over still
gridlines). In a preset the light runs down the shapes as a wave, one stagger step apart.

`animation` picks `shimmer` (a soft light sweeping across), `pulse` (breathing in place) or `none`.
Under reduced motion every skeleton is still.

`SkeletonSwap` shows a fallback while `loading` and the content after.

The motion variant of `SkeletonSwap` resolves the placeholder into the content: the content sharpens from a slight blur as it fades in while the placeholder fades out over it, in the same box.

## Props

### Skeleton, SkeletonLine, SkeletonCircle

Every prop of a `span` is accepted as well.

## Accessibility

- Each shape is hidden from assistive technology.
- A preset is one busy status that announces its label once, not once per shape.
- `SkeletonSwap` sets `aria-busy` while loading.
- Under reduced motion nothing shimmers or pulses.
