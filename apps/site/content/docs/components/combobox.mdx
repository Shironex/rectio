## Install

```sh
pnpm dlx rectio add combobox
```

`field`, `select` and `theme-scope` install with it.

## Usage

```tsx
import { Combobox, ComboboxContent, ComboboxInput, ComboboxItem } from '@/components/ui/combobox';
import { Field, FieldLabel } from '@/components/ui/field';

<Field>
  <FieldLabel>Customer</FieldLabel>
  <Combobox items={customers} value={customer} onValueChange={setCustomer}>
    <ComboboxInput placeholder="Search customers" />
    <ComboboxContent>
      {(item) => (
        <ComboboxItem key={item.value} value={item} hint={item.city}>
          {item.label}
        </ComboboxItem>
      )}
    </ComboboxContent>
  </Combobox>
</Field>;
```

Reach for Combobox over Select when the list is long enough that people would rather type than
scroll. Items shaped `{ value, label }` need no more setup; for other shapes pass
`itemToStringLabel`. When nothing matches, the list says "No results"; set `emptyMessage` for other
wording.

### Groups

Pass groups as `items` (`{ label, items }`) and render each with `ComboboxGroup`, whose function
child renders the group's items. A group with no match hides.

### Results from a server

Fetch in `onInputValueChange`, swap `items` when the answer arrives, and set `filter={null}` so the
client does not filter the server's matches again. While the request runs, `loading` on
`ComboboxContent` shows "Searching…" in the list, announced politely, and marks the list busy. Keep
the chosen item in `items` so it still shows while new results load.

### Creating an item

Pass `onCreate` and, when the typed text matches no item exactly, the list ends with
`Create "acme"`. Choosing it calls `onCreate("acme")` and closes the list; add the item and select
it. The value must be controlled for the new item to show. Creating works with a flat list of
items.

The motion variant opens the list with a spring from the input and glides the highlight between
options, as Select does. Typing never animates: the list filters in place.

`onValueChange`, `inputValue`, `onInputValueChange`, `filter`, `itemToStringLabel`, `disabled`,

## Accessibility

- The input is named by its `FieldLabel`; Arrow Down opens the list, the arrows move and Enter
  picks. Escape closes the list.
- Loading, empty and status lines are announced politely as they change.
- The chosen item carries a check mark as well as a heavier weight; the create option carries a
  plus sign.
- The clear and open buttons are named, and 44px wide on touch screens.
