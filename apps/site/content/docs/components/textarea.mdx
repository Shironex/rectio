## Install

```sh
pnpm dlx rectio add textarea
```

`field` installs with it.

## Usage

```tsx
import { Field, FieldLabel } from '@/components/ui/field';
import { Textarea } from '@/components/ui/textarea';

<Field>
  <FieldLabel>Note for the approver</FieldLabel>
  <Textarea value={note} onValueChange={setNote} maxLength={240} showCount />
</Field>;
```

The field starts `minRows` lines tall and grows with its text up to `maxRows`, then scrolls. It
measures and sets its height in one pass before the browser paints, so the page below never jumps,
whether the text is typed or set by the app. Set `minRows` and `maxRows` to the same number for a
fixed height.

With `maxLength` and `showCount`, the count under the field reads `120 / 500`. Near the limit it
turns to the warning colour and adds the characters left in words; at the limit it says so in the
negative colour. `warnAt` sets how close counts as near; the default is a tenth of the limit, at
least 10 characters.

There is no motion variant: a text field that animates as you type only slows typing down.

Every prop of a native `textarea` is accepted as well, except `rows`, which `minRows` sets.

## Accessibility

- Named by its `FieldLabel`; the description and the error are linked to it.
- The count is announced politely only near the limit, as "12 characters left" or "Limit
  reached", after a short pause in typing so a fast typist hears one number, not every keystroke.
- Near and at the limit the count carries a warning icon and words, not colour alone.
- Uses the same invalid, disabled and focus styles as `Input`.
