## Install

```sh
pnpm dlx @rectio/cli add event-card
```

`avatar-group` installs with it.

## Usage

```tsx
import { EventCard } from '@/components/ui/event-card';

<EventCard
  title="Audit kickoff"
  start={new Date(2026, 2, 19, 9, 30)}
  end={new Date(2026, 2, 19, 11)}
  tone="warning"
  location="Floor 3"
  attendees={[{ name: 'Ines Duarte' }, { name: 'Callum Ross' }]}
  locale="en-GB"
  onSelect={() => openEvent('kickoff')}
/>;
```

The full card shows the time with its length, the place, and the attendees with their names. The
compact card is the title and the time on two lines, for lists and grids such as the
[week agenda](/docs/blocks/saas/week-agenda).

`tone` colours the card by kind of event (a meeting, a deadline, time off) from the status tokens.
`status` says how sure it is: a tentative event has a dashed edge and the word "Tentative", a
cancelled one turns neutral, is struck through and says "Cancelled". An event past midnight writes
both days, and `allDay` reads "All day".

With `onSelect`, the title becomes a button that covers the card. `triggerProps` passes a roving
`tabIndex` or a key handler to that button.

`formatEventTime` and `formatEventLength` are exported for your own lists.

## Accessibility

- The card is an `article`; with `onSelect`, its one button is named by the title and described by
  the time, status and place.
- Status is a word and an icon as well as a style, so it never rests on colour alone.
- Times use tabular figures and the locale's clock.
