## Install

```sh
pnpm dlx @rectio/cli add docs-feedback
```

The motion variant is `motion-docs-feedback`. It installs the plain block too and changes only how the block moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

A one-question widget for the foot of a page: a yes or no vote, an optional comment that counts down to its limit, a sending state, and an error that keeps what the reader wrote. It sends nothing itself. In the motion variant the thanks fades in.

## Usage

Pass `onSubmit`: it receives `{ helpful, comment }` and sends it wherever you collect feedback, such as an analytics event, a form endpoint or an issue tracker. Return a promise: while it is pending the form shows its sending state, and if it rejects the error shows and the comment stays. `onVote` fires on the vote itself, before any comment, if you count votes separately. The preview here sends nothing and always succeeds.

## Accessibility

- The vote buttons say whether they are pressed.
- The thanks is announced as a status message.
- Focus moves to the comment field after a vote.
