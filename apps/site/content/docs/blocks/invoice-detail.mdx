## Install

```sh
pnpm dlx rectio add invoice-detail
```

The motion variant is `motion-invoice-detail`. It installs the plain block too and changes only how the
block enters.

## Usage

Totals follow invoice practice: each line's net is rounded to the cent, VAT is computed once per
rate on the summed nets and rounded once, so the VAT lines match what a tax authority recomputes.
All sums run in minor units.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source is in
the repository, under `packages/blocks`.

## Messages

Every word the block prints, including what screen readers hear, comes from `messages`. The full
English defaults are exported as `INVOICE_DETAIL_MESSAGES`, typed as `InvoiceDetailMessages`. Pass only the keys you
change; a message that counts or names a figure is a small function, so a language can order the
words and choose its plural form with `plural()`.

```tsx
import { plural } from '@rectio/blocks';

<InvoiceDetail
  invoice={invoice}
  currency="PLN"
  locale="pl-PL"
  messages={{
    heading: (number) => <>Faktura {number}</>,
    billedTo: 'Nabywca',
    balanceDue: 'Do zapłaty',
    overdueDescription: (days, due) =>
      `${days} ${plural(days, { one: 'dzień', other: 'dni' }, 'pl-PL')} po terminie, termin ${due}`,
  }}
/>;
```

A complete set typed as `InvoiceDetailMessages` fails to compile when a key is missing.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`documentTotals(lines, payments, currency)` and `paymentState(invoice, totals, today)`.

## Accessibility

- The totals are a `dl`; the balance due is its own row, in words as well as weight.
- On narrow widths quantity, price and VAT fold under each line's description instead of scrolling.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
