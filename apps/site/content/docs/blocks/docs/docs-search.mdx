## Install

```sh
pnpm dlx rectio add docs-search
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

A search dialog with a trigger, grouped results with the query marked, recent searches and suggestions. It is not tied to an index: it takes a provider, a function from a query to results. `createLocalSearch` builds one over documents you hand it, in the browser, with no service. The preview searches three pages of the Halyard docs: press the trigger and type "retry".

## Usage

For a small site, build the provider from documents you generate at build time:

```tsx
import { DocsSearch, createLocalSearch } from '@rectio/blocks/docs';

const search = createLocalSearch(documents, { limit: 12 });

<DocsSearch search={search} onNavigate={router.push} />;
```

A document has an `id`, `title`, `href`, optional `group`, `description` and `headings`, and the page's text as `content`. Matches in a heading come back as their own result under the page. For a hosted index (Algolia, Orama, your own route), pass any function with the provider shape instead: it receives the query and an `AbortSignal` and returns results or a promise of them, so a newer keystroke cancels an older request. The `mod+k` shortcut opens the dialog from anywhere.

## Accessibility

- The search opens as a modal dialog and the keyboard works throughout: arrow keys move through results and Enter opens one.
- Focus returns to the trigger when the dialog closes.
