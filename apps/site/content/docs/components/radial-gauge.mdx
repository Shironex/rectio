## Install

```sh
pnpm dlx @rectio/cli add radial-gauge
```

## Usage

```tsx
import { RadialGauge } from '@/components/ui/radial-gauge';

<RadialGauge
  label="Quota attainment"
  value={0.82}
  max={1.25}
  target={1}
  marker={{ value: 0.74, label: 'Pace' }}
  bands={[
    { to: 0.7, label: 'Behind' },
    { to: 0.95, label: 'Close' },
    { to: 1.25, label: 'Ahead' },
  ]}
  format="percent"
/>;
```

The arc fills from `min` to the value over a 240 degree sweep. The figure is written in the middle
with its share of the target under it, and the band it falls in is named in words, so the arc is a
picture of the numbers rather than the only place they live.

`target` is a solid tick across the arc; `marker` is a second, dashed one, such as where the value
should be by now. `bands` are drawn as a thin outer ring and listed under the gauge with their ranges;
by default they take the warm sequence steps, with the quiet reference grey for the good band, so
no band shares the arc's colour; `better="lower"`
turns that around for spend or latency. For a figure with no target or bands, a plain
[Meter](/docs/components/meter) may be all you need.

The motion variant sweeps the arc to its value on first view and glides to new figures.

## Accessibility

- A meter named by `label`, with its value text saying the figure, the scale, the target and the
  band in words.
- The figure in the middle is hidden from screen readers, since the meter says it.
- The list under the gauge names each band with its range, the target and the marker.
- The target is solid with a halo and the marker dashed, so they read apart without colour.
