## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add profile-settings
```

The motion variant is `motion-profile-settings`. It installs the plain block too and changes only how the
block enters.

## Usage

Pass the saved `profile`. The form edits a draft of it: a bar at the end counts the unsaved
changes and offers Discard and Save, and `onSave` gets the trimmed values with the list of fields
that changed. Pass the saved profile back after saving and the form starts again from it.

A changed email says a confirmation link will go to the new address; an unverified one shows a
badge and, with `onResendVerification`, a resend link. `onAvatarChange` gets the chosen image file
to upload. `onDeleteAccount` adds a danger zone that asks for the email typed back before it calls
you.

## Logic

`profileErrors`, `profileChanges`, `profileEmailChanged`, `profileDeleteConfirmed` and
`timeZoneLabel` are exported and tested.

## Accessibility

- Every field has a visible label and its error tied to it; the count of unsaved changes is announced politely.
- The picture button opens the file picker; the picker input itself stays out of the tab order.
- Deleting asks for the email typed back in a dialog, and the delete button stays disabled until it matches.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
