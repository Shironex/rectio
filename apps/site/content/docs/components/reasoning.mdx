## Install

```sh
pnpm dlx @rectio/cli add reasoning
```

## Usage

```tsx
import { Reasoning } from '@/components/ui/reasoning';

<Reasoning status={thinking ? 'thinking' : 'done'} duration={seconds}>
  <Markdown size="sm" streaming={thinking}>
    {reasoning}
  </Markdown>
</Reasoning>;
```

While the model thinks it is open and says Thinking; once done it folds to "Thought for 12 seconds"
so the answer leads. A reader who opens or closes it keeps their choice. Pass `open` to control it,
or `followStatus={false}` to leave it as the reader set it.
