## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add ledger
```

The motion variant is `motion-ledger`. It installs the plain block too and changes only how the
block enters.

## Usage

The journal keeps each entry together, credits indented under debits as a journal is written by
hand. Choosing an account shows its ledger with an opening balance, a running balance signed by
the account's normal side and a closing balance. Any entry that does not balance is marked on its
row, and the check under the table names the side that is heavier and by how much.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source comes with the license.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`journalTotals`, `unbalancedEntries` and `runningBalances(lines, account, opening, currency)`.

## Accessibility

- On narrow widths debit and credit fold into one Amount column, each figure marked Dr or Cr, and read as debit or credit to screen readers.
- The balance check is a status message, announced when it changes.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
