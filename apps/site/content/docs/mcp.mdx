---
title: MCP server
description: Let a coding agent read rectio items, tokens and source instead of guessing.
---

`rectio mcp` runs a read-only [MCP](https://modelcontextprotocol.io) server on stdio. A coding agent
such as Claude Code, Cursor or VS Code's agent mode can look up what rectio has, read a component's
source with your aliases, and get the exact command to add it.

It is part of the CLI, so one install covers both. It uses the same registry lookup (`--registry`,
`RECTIO_REGISTRY_URL`, then `rectio.json`, then the published registry). It never writes files: `get_add_command` returns the command for you or the agent
to run.

## Tools

| Tool              | Use it to                                                                                           |
| ----------------- | --------------------------------------------------------------------------------------------------- |
| `list_items`      | See what exists, filtered by `type`.                                                                |
| `search_items`    | Find items by words in the name, title, categories and description.                                 |
| `get_item`        | Read one item: description, versions, what installs with it, npm packages, files.                   |
| `get_item_source` | Read the source of an item or one of its files. Imports use your aliases when `rectio.json` exists. |
| `get_tokens`      | Get the token names and values of a theme and mode, with the Tailwind utility for each.             |
| `get_docs`        | Get an item's usage notes and exports, or the general rules without an item.                        |
| `get_add_command` | Get the exact `rectio add ...` command, with what else it installs.                                 |

## Set up

The server runs in the project folder the editor opens, which is where it finds `rectio.json`.

<Tabs items={['Claude Code', 'Cursor', 'VS Code']}>
<Tab value="Claude Code">

Add it for the project; this writes `.mcp.json`. Drop `--scope project` to add it for yourself only.

```sh
claude mcp add rectio --scope project -- rectio mcp
```

Or write `.mcp.json` yourself:

```jsonc title=".mcp.json"
{
  "mcpServers": {
    "rectio": {
      "command": "rectio",
      "args": ["mcp"],
    },
  },
}
```

### A local registry

Point the server at a registry folder or the dev server with `--registry`:

```jsonc
"args": ["mcp", "--registry", "../rectio/packages/registry/dist/registry"]
```

### Windows

On native Windows, if the editor cannot start the `rectio` command (a `.cmd` shim), use
`cmd /c rectio mcp`: set `"command": "cmd"` and `"args": ["/c", "rectio", "mcp"]`.
