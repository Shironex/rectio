## Install

```sh
pnpm dlx @rectio/cli add breakdown-table
```

The motion variant is `motion-breakdown-table`; the rows fade up on first view.

## Usage

```tsx
import { BreakdownTable } from '@rectio/blocks/analytics';

<BreakdownTable
  title="Revenue by channel"
  items={[
    { id: 'organic', label: 'Organic search', value: 42180, previous: 38940 },
    { id: 'direct', label: 'Direct', value: 31260, previous: 32100 },
  ]}
  comparison="vs October"
  format="currency"
  currency="EUR"
/>;
```

Each row writes its figure, its share of the total and, when it has a `previous` figure, its change.
With `bars` (the default) a bar under the name shows the row against the largest one; `compact` drops
the bars for a long list in tight rows. On a narrow card the share moves under the figure.

Past `limit` (eight by default) the smallest items gather into one others row, which stays last
whatever the order; **Show all** lists every row. The column headers sort by name, figure or change,
and rows without a change sink to the end. A totals row closes the table; pass `total={false}` to
leave it out.

## Logic

`breakdownModel(items, { sort, limit, locale })` gives the sorted rows with their shares, changes and
bar lengths, the others row, the total and its change.

## Accessibility

- A region and a table named by the title, with real column headers.
- Each sortable header is a button, and `aria-sort` says the current order.
- Every figure, share and change is text; the bars are hidden from screen readers.
- A change says its direction and whether it is better in words; a row without one says so.
- **Show all** says whether the full list is open with `aria-expanded`.
