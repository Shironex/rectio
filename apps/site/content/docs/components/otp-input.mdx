## Install

```sh
pnpm dlx @rectio/cli add otp-input
```

`field` installs with it.

## Usage

```tsx
import { Field, FieldError, FieldLabel } from '@/components/ui/field';
import { OtpInput } from '@/components/ui/otp-input';

<Field invalid={wrong}>
  <FieldLabel>Verification code</FieldLabel>
  <OtpInput groups={[3, 3]} value={code} onValueChange={setCode} onComplete={verify} />
  <FieldError>That code is not right.</FieldError>
</Field>;
```

`length` sets the number of slots, from 4 to 8 (6 by default). `groups` splits them into chunks
with a separator between, such as `[3, 3]` for `123 456`; groups that do not add up to the length
are ignored. `type="alphanumeric"` takes letters as well as digits, for recovery and invite codes.
`mask` hides the characters, for a PIN.

Focus moves to the next slot as each character lands, and Backspace moves back. Pasting a whole
code fills every slot, and the browser can offer a code from a text message, since the first slot
carries `autocomplete="one-time-code"`. `onComplete` runs once every slot is filled.

There is no motion variant: characters arrive in quick succession, and animating them would only
slow entry down.

## Props

Every prop of Base UI's `OTPField.Root` is accepted as well: `value`, `defaultValue`,
`onValueChange`, `mask`, `autoSubmit`, `name`, `disabled` and more.

## Accessibility

- The slots form a group named by the `FieldLabel` and described by the description and error.
  The first slot takes the label too; the others are named by position.
- Numeric codes open the numeric keyboard on phones.
- An invalid code shows the error with an icon and text, and every slot turns red.
