## Install

```sh
pnpm dlx @rectio/cli add message-actions
```

## Usage

```tsx
import {
  MessageActions,
  MessageCopyAction,
  MessageFeedback,
  MessageRegenerateAction,
} from '@/components/ui/message-actions';

<MessageActions>
  <MessageCopyAction value={() => markdownToText(reply)} />
  <MessageFeedback value={rating} onValueChange={setRating} />
  <MessageRegenerateAction onClick={regenerate} />
</MessageActions>;
```

Copy turns into a check for two seconds and says Copied. The thumbs toggle; pressing the chosen one
again clears it. `MessageAction` takes any icon and label for actions of your own.

## Accessibility

- A `toolbar`: one tab stop, then the arrow keys, Home and End move between actions.
- Every icon has a name and a tooltip; the chosen thumb is `aria-pressed` and filled.
