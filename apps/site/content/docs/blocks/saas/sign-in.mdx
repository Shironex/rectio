## Install

```sh
pnpm dlx @rectio/cli add sign-in
```

The motion variant is `motion-sign-in`. It installs the plain block too and changes only how the
block enters.

## Usage

The block holds only what is typed. It checks the fields on submit and calls `onSubmit` with valid
values; your app signs in, sets `pending` while it waits and passes the refusal back as `error`.
With `onMagicLink`, a second button switches the form to a passwordless link, and
`magicLinkSentTo` turns the form into a check-your-inbox note.

Provider buttons go in the `social` slot. `SocialButton` draws one at the form's width; pass your
provider's own mark as its `icon`.

## Logic

`signInErrors` returns the message per field, so a server can answer with the same words. It
checks the password for presence only: its rules belong to sign up.

## Accessibility

- Errors appear after the first submit, under their field and tied to it; a server refusal is announced at once.
- The email and password fields carry `autocomplete` purposes, so password managers fill and save them.
- The show password button says what it will do and is reachable after the field.
- Works in light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
