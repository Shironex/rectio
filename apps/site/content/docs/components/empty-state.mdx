## Install

```sh
pnpm dlx rectio add empty-state
```

## Usage

```tsx
import { Button } from '@/components/ui/button';
import { EmptyState } from '@/components/ui/empty-state';

<EmptyState
  icon={<UsersThreeIcon weight="duotone" />}
  title="Invite your team"
  description="Approvers and accountants see the reports you share with them."
  actions={<Button>Invite people</Button>}
/>;
```

Say what is missing in a few words, then the next step. One primary action is usually enough.
`size` scales it from a slot in a panel (`sm`) to a whole page (`lg`); `variant="dashed"` frames the
area, for an empty slot or a drop zone. `media` takes a larger picture in place of the icon tile.

The pro blocks build their empty notes on this component.

## Props

Every prop of a `div` is accepted as well, including `role`.

<TypeTable

    },
  }}
/>

## Accessibility

- The icon is decorative; the title says what is missing.
- Give it `role="status"` when it replaces content that was loading, so the result is announced.
