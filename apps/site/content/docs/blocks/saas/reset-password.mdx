## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add reset-password
```

The motion variant is `motion-reset-password`. It installs the plain block too and changes only how the
block enters.

## Usage

The flow has four steps and your app holds which one shows: `request` asks for the email and calls
`onRequest`; `sent` says where the link went, with `onResend` and `onRestart`; `reset`, opened from
the emailed link, takes the new password twice against the same rules as sign up and calls
`onReset`; `done` leads back to sign in. Keep the reset token in your app and send it with the new
password.

When the token has expired, pass the reason as `error` on the reset step: with `onRestart` the
message offers a new link.

## Logic

`resetRequestError` and `newPasswordErrors` return the messages, and the password rules are the
shared `passwordChecks` and `passwordAccepted`.

## Accessibility

- The sent step never says whether an account exists, so the form cannot be used to find out who has one.
- Each password rule says met or not met to screen readers; a mismatch is tied to the confirm field.
- The new password fields carry `autocomplete="new-password"` so password managers offer and save it.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
