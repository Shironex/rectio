## Install

```sh
pnpm dlx @rectio/cli add bank-reconciliation
```

The motion variant is `motion-bank-reconciliation`. It installs the plain block too and changes
only how the block enters and how rows leave a filtered view.

## Usage

Every statement line shows its match, a suggested match or nothing yet. A suggestion has exactly
the same amount, to the cent, and either the same reference (any date) or a date within
`windowDays`. Match accepts it, Unmatch undoes a pair. Book entries with no statement line are
listed under the table, since they explain part of the difference.

The block holds no pairs: you pass `matches` and get `onMatch(bankId, bookId)` and
`onUnmatch(bankId)` back. `reconciliationReducer` keeps a list of pairs one to one:

```tsx
import { BankReconciliation, reconciliationReducer } from '@rectio/blocks';

const [matches, dispatch] = useReducer(reconciliationReducer, savedMatches);

<BankReconciliation
  statement={statement}
  book={entries}
  matches={matches}
  statementBalance={53_236.27}
  bookBalance={48_310.55}
  currency="EUR"
  account="Business current •• 4821"
  period="March 2026"
  onMatch={(bankId, bookId) => dispatch({ type: 'match', bankId, bookId })}
  onUnmatch={(bankId) => dispatch({ type: 'unmatch', bankId })}
  onReconcile={closePeriod}
/>;
```

Mark reconciled stays disabled, still focusable and described, until the difference is zero and
nothing is left unmatched on either side.

## Messages

Every word the block prints, including what screen readers hear, comes from `messages`. The full
English defaults are exported as `BANK_RECONCILIATION_MESSAGES`, typed as
`BankReconciliationMessages`. Pass only the keys you change; a message that counts or names a figure
is a small function, so a language can order the words and choose its plural form with `plural()`.

```tsx
import { plural } from '@rectio/blocks';

<BankReconciliation
  {...props}
  currency="PLN"
  locale="pl-PL"
  messages={{
    title: 'Uzgodnienie bankowe',
    match: 'Dopasuj',
    statementLines: (count) =>
      `${count} ${plural(count, { one: 'pozycja', few: 'pozycje', many: 'pozycji', other: 'pozycji' }, 'pl-PL')} na wyciągu`,
  }}
/>;
```

A complete set typed as `BankReconciliationMessages` fails to compile when a key is missing.

## Logic

The logic is exported and tested on its own, so a server can match the same way:
`suggestMatches(statement, book, matches, currency, { windowDays })`, `referencesMatch(a, b)`,
`reconciliationSummary({ statement, book, matches, statementBalance, bookBalance, currency })` (the
difference, what the unmatched items on each side add up to and what they leave unexplained, all in
minor units) and `reconciliationReducer(matches, command)`.

## Accessibility

- Each line's state is a badge with a word and an icon (matched, suggested, unmatched), never colour alone.
- Match and Unmatch name the line and the entry they act on for screen readers.
- The filter is one toggle group: arrow keys move between options and the pressed one is announced.
- Mark reconciled stays focusable while disabled and is described by the line that says what is left.
- Every figure is in tabular numerals with a true minus sign; money in carries a plus.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
