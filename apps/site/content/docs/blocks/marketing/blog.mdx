## Install

```sh
pnpm dlx rectio add blog
```

The motion variant is `motion-blog`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

The latest articles as a large lead and a grid or as dated rows, and one article laid out at a
reading measure.

## Usage

`ArticleList` takes summaries with an ISO `date`; set `layout="list"` for dated rows and `viewAll`
for a link to every article. `ArticleLayout` takes the article body as plain HTML elements, set in
the prose styles; give each `h2` the id of the matching entry in `headings` and an "On this page"
list appears beside it on wide screens.

## Logic

`readingMinutes(text)`, `formatDate(date, locale)` and `slugify(text)` are exported.

## Accessibility

- Each card is one link, named by the article's title, so it reads once; the whole card is the hit area.
- Dates use a machine-readable `time` element.
- Article text is set at a reading measure with real headings, and "On this page" is a labelled navigation.
