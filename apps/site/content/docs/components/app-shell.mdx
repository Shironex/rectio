## Install

```sh
pnpm dlx @rectio/cli add app-shell
```

`sidebar`, `tooltip` and their dependencies install with it.

## Usage

```tsx
import { AppShell, AppShellHeader } from '@/components/ui/app-shell';
import { Breadcrumb } from '@/components/ui/breadcrumb';
import { Sidebar } from '@/components/ui/sidebar';

<AppShell
  sidebar={<Sidebar>{/* header, content, footer */}</Sidebar>}
  header={
    <AppShellHeader
      title={<Breadcrumb items={items} />}
      actions={<Button size="sm">New invoice</Button>}
    />
  }
>
  {/* the page */}
</AppShell>;
```

`AppShell` wires a `SidebarProvider`, a `TooltipProvider`, the sidebar, a sticky header and the page
inside a `main` landmark. The page scrolls the window, not a box inside it, so browser find, scroll
restoration and pull to refresh behave as on any page. The header sticks to the top.

The first Tab stop of the page is a skip link that jumps past the navigation to `main`. It is hidden
until focused.

The shell accepts the props of `SidebarProvider` (`defaultCollapsed`, `onCollapsedChange`,
`shortcut`), so the folded state can be saved and the shortcut changed here.

`AppShellHeader` puts the `SidebarTrigger`, a divider, the title and the actions on one line. Set
`showTrigger={false}` for a page without a sidebar toggle.

This preview sits in a fixed height box so the page can scroll inside it; in an app the shell takes
the whole window (`min-h-dvh`).

## Props

### AppShell

Takes the props of `SidebarProvider` as well.

  type={{

Every `header` prop is accepted as well, except `title`.

## Accessibility

- The skip link is the first Tab stop and moves focus to `main`, which is a named landmark.
- Landmarks: the sidebar `nav`, the header, and `main`.
- Everything about the sidebar and its trigger applies, including the phone sheet.
