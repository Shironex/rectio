## Install

```sh
pnpm dlx rectio add docs-api-reference
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

Three ways to document an API: a props table, a signature card for a function, method, class or hook, and an HTTP endpoint with parameters, a request and example responses. The props table is a table in a wide column and a list of entries in a narrow one, so it never scrolls sideways.

## Usage

Rows, parameters and responses are data, so they can come from your own type extraction. Pass `tokens` from the same highlighter as your code blocks to colour a signature or an example. `MethodBadge` draws the HTTP verb on its own. All three are in `docsMdxComponents`, so an MDX page can write them directly.

## Accessibility

- The props table has column and row headers; the narrow layout is a description list with the same names.
- Required and deprecated rows say so in text.
