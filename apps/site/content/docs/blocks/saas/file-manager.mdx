## Install

```sh
pnpm dlx rectio add file-manager
```

The motion variant is `motion-file-manager`. It installs the plain block too; rows arrive and leave
in place.

## Usage

Pass the path from the root and what the current folder holds. Folders come first, then files with
an icon for their kind, size, owner and last change. Sort by name (as people read them, so Q2 before
Q10), last modified or size. Each row has a menu to open, rename in place, download and delete;
select rows to download or delete several at once. Deleting always asks first and warns when a
folder takes its contents with it.

A folder longer than `pageSize` (50 by default) pages, with a pager and a line such as "1 to 50 of 120
items" announced politely beside it; pass `Infinity` to turn paging off. The page resets when the
folder or the sort changes. To page on the server, pass only the current page as `entries`, the
folder's count as `totalEntries` and fetch in `onPageChange`. Use `canModify` to say which entries may
be renamed or deleted; bulk delete covers only the entries it allows. After a delete, focus moves to
the next row, else the previous one, else the heading or the empty state.

Pass `storage` for a usage meter (a bar, with the amount in words) that warns from 80 percent. On narrow widths size, owner and date fold
under the name.

## Logic

Sorting and checks are exported and tested on their own: `sortFileEntries`, `fileKindOf`,
`fileNameError`, `fileEntriesSize`, `storageLevel` and `filePage` (`filePage(total, pageSize, page)` gives
the page, the page count and the first and last item).

## Accessibility

- The storage meter reads as "X of Y" in words.
- The path is a labelled navigation with the current folder marked.
- Every checkbox, menu and rename field names the file it acts on; rename errors are tied to the
  field and Escape cancels.
- The range of items shown is announced politely as the page changes.
- The selection count is read out as it changes; file kinds are written for screen readers.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity and renders the plain block under reduced motion.
