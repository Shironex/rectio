## Install

```sh
pnpm dlx @rectio/cli add time-field
```

`field` installs with it.

## Usage

```tsx
import { Field, FieldLabel } from '@/components/ui/field';
import { TimeField, type TimeValue } from '@/components/ui/time-field';

const [starts, setStarts] = useState<TimeValue | null>({ hour: 9, minute: 30 });

<Field>
  <FieldLabel>Meeting starts</FieldLabel>
  <TimeField locale="en-GB" value={starts} onValueChange={setStarts} step={15} />
</Field>;
```

The value is `{ hour, minute }` on a 24 hour clock, or `null` while a segment is empty. The face
follows the locale: `en-GB` shows `14:00`, `en-US` shows `02:00 PM` with an AM or PM segment. Pass
`hourCycle` to choose the clock yourself.

Each segment is its own spin button. Type digits and focus moves on once a segment is full; arrow
keys step it. `min` and `max` bound the arrow keys, and a typed time outside them marks the field
invalid, so pair it with a `FieldError`. With `name`, a hidden input submits the time as `HH:mm`.

`formatIsoTime`, `parseIsoTime`, `formatTime`, `resolveHourCycle` and `stepTime` are exported for
your own storage and messages.

## Accessibility

- The hour segment is named by the `FieldLabel`; minutes and the period carry their own names.
  Each is a spin button with its value and range read out.
- Arrow Up and Arrow Down step a segment, Page Up and Page Down step by 3 hours or 15 minutes, Home
  and End jump to its ends. Arrow Left and Right move between segments, in reading order for right
  to left scripts too.
- Backspace clears a segment and then moves back. A colon, a full stop or a space moves on. A and P
  set the period.
- Digits arrive through the input's own change, so phone keyboards type into it like any field.
