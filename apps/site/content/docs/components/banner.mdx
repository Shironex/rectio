## Install

```sh
pnpm dlx rectio add banner
```

## Usage

```tsx
import { Banner } from '@/components/ui/banner';

<Banner dismissible action={<a href="/changelog">See what changed</a>}>
  Bulk approvals are here: approve up to 50 expenses in one go.
</Banner>;
```

A banner speaks for the whole app: scheduled maintenance, a new feature, an account that needs
attention. Show one at a time, at the top of the app. For a message about one part of the page, use
an Alert there.

`accent` is the one loud banner, in the brand's own fill; `danger` fills too. `neutral`, `info` and
`warning` are tinted bands.

The motion variant lifts away when dismissed.

Every prop of a `section` is accepted as well.

## Accessibility

- A region named by `label`, so it can be found and skipped.
- Not a live region: it is part of the page when it loads.
- The dismiss button is named and keyboard reachable.
