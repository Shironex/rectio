## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add kpi-row
```

The motion variant is `motion-kpi-row`. It installs the plain block too and changes only how the
block enters.

## Usage

A change says its direction three ways: an arrow, a signed figure and words for screen readers
("better" or "worse"). Colour follows `better`, so falling spend is good news in green and rising
spend is bad news in red. Percentages change in points, money in percent; a zero base reads "New".

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source comes with the license.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`kpiDelta(kpi)` returns the direction, the change and whether it is favourable.

## Accessibility

- The sparkline is decorative and hidden from assistive technology: the figure and its change say the same in words.
- The row is a `dl`: each label names its figure.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
