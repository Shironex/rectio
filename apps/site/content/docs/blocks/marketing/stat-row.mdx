## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add stat-row
```

The motion variant is `motion-stat-row`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

Three or four big figures with what each one counts, divided by hairlines. With a `lead`, a sentence
sets them up on the left. In the motion variant each figure counts up once, on first view, and
lands exactly on its value.

## Usage

A stat's `format` says how to write it: `number` in full, `compact` shortened (14.2M), `percent`
from a fraction (0.998 is 99.8%) or `currency` shortened. `suffix` adds text after the figure.

## Logic

`formatStat(stat, value, locale)` is exported, so a server or an image generator can write the same
figure the block shows.

## Accessibility

- The section is named by the lead or by `label`.
- The count-up lands exactly on its value.
- Under reduced motion the motion variant renders the plain block.
