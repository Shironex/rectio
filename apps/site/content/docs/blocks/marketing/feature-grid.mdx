## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add feature-grid
```

The motion variant is `motion-feature-grid`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

What the product does, in three layouts: a calm ruled grid for a long list, rows with the live
feature beside the copy, or a bento of tiles with the product shown working.

## Usage

All three take a `title`, `description`, `eyebrow` and `tone`. Keep `FeatureRows` to two or three
rows, then change the layout. In `FeatureBento`, plan the sizes so each row fills: a wide and a
regular, three regulars, or a tall beside two stacked.

## Accessibility

- Each section is named by its heading; icons are decorative and the title carries the meaning.
- Layouts reflow to one column on narrow screens and read in source order.
