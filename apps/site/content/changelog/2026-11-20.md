## Kit

- 59 components: forms, overlays, navigation, data display and finance primitives.
- 61 blocks: 14 finance, 18 SaaS and app, 16 marketing and 13 docs blocks.
- 73 motion twins with the same names and props as the plain items, plain again under reduced motion.

## Templates

- 5 templates: a finance back office, a help desk admin, a SaaS marketing site, a product launch page and a docs site.
- A live preview of every template, page by page, at desktop, tablet and phone width.

## Themes

- 2 themes, `default` and `ledger`, each in light and dark.

## CLI

- `@rectio/cli` on npm with `init`, `add`, `diff`, `list`, `search` and `update`, integrity checks and a lockfile that respects your edits.
- `rectio mcp`, an MCP server that gives coding agents seven read only tools to look up items, tokens, docs and source.
- A notice when a newer CLI is on npm, and a hint after `add` and `list` when installed items have newer versions.

## Docs and site

- A docs page for every component and block, with live previews and the source beside each motion preview.
- Pages for the [CLI](/docs/cli), the [registry](/docs/registry) and the [MCP server](/docs/mcp).
