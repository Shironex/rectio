## Install

```sh
pnpm dlx @rectio/cli add line-chart
```

## Usage

```tsx
import { LineChart } from '@/components/ui/line-chart';

<LineChart
  series={[
    { id: 'this', label: 'This quarter', points: thisQuarter },
    { id: 'last', label: 'Last quarter', points: lastQuarter, dashed: true },
  ]}
  format="currency"
  currency="EUR"
  references={[{ value: 2000, label: 'Daily target €2,000' }]}
/>;
```

Points are `{ date, value }`. The step (hour, day or month) is read from the data, and the axis picks
the finest tick spacing that fits the width: hours, days, weeks starting on Monday, months, quarters or
years, written in the locale. The year appears where the range crosses one, and midnight names its day.

A `null` value, or a run of missing points longer than three steps, breaks the line, so a broken
import reads as missing rather than as a straight slope. Dash a series for a forecast or a previous
period; series past the third are dashed for you.

Charts live in their own entry, `@rectio/ui/charts`, so an app that draws none never ships the chart
library. The motion variant draws each line along time the first time it is seen, and later updates
glide to the new figures; reduced motion keeps both still.

## Accessibility

- A figure with a summary read before the plot: the range, and for each series its first, last, peak
  and change. Pass `summary` to say it in your own words.
- Every chart has a table twin, in the page for screen readers and shown on request with **Show
  table**. The legend and the table use the same names and figures as the tooltip.
- The plot takes focus: arrow keys move from point to point, and the tooltip follows.
- Colours come from the three chart series tokens, which stay apart for every common colour vision
  type; series past the third repeat a colour and turn dashed, so a line never rests on colour alone.
- Figures use the true minus sign, so signed values line up.
