## Install

```sh
pnpm dlx @rectio/cli add kbd
```

## Usage

```tsx
import { Kbd, KbdShortcut, useShortcut } from '@/components/ui/kbd';

<KbdShortcut shortcut="mod+shift+i" />

<Kbd>Esc</Kbd>;

useShortcut('mod+shift+i', () => openNewInvoice());
```

A shortcut is a string of keys joined by `+`, such as `mod+k`, `shift+mod+p` or `g`. Case does not
matter. `mod` is Command on Apple platforms and Control everywhere else, so one string serves every
user. The first render on the server shows the Control form and is corrected on a Mac right after
hydration, so the markup never mismatches.

`useShortcut` listens on the whole page. A shortcut with no modifier (`g`, `?`) is ignored while the
user types in a field, so it never eats a letter. A shortcut with Command, Control or Alt fires in
fields too; set `allowInFields: false` for one that an editor also uses, such as `mod+b`.

The same helpers are exported for your own use: `parseShortcut`, `shortcutKeys`, `shortcutLabel`,
`ariaKeyShortcut`, `matchesShortcut` and `useIsMac`.

## Props

### Kbd

A `kbd` element drawn as one keycap. Every `kbd` prop is accepted.

### KbdShortcut

Every `kbd` prop is accepted as well, except `children`.

## Accessibility

- `KbdShortcut` hides the keycaps from screen readers and announces the shortcut in words instead
  ("Command K"), so it is not read symbol by symbol.
- A shortcut is only a hint: the app binds it. Where a control has a shortcut, `Menu`, `CommandMenu`
  and `Sidebar` also set `aria-keyshortcuts` on it.
- Never make a shortcut the only way to an action.
