## Install

```sh
pnpm dlx @rectio/cli add api-keys
```

The motion variant is `motion-api-keys`. It installs the plain block too; keys arrive and leave in place.

## Usage

Pass the keys (only their public prefix, never the secret) and the scopes your API offers.
`onCreate` gets a name, a scope and an expiry date; create the key on your server, then pass its
secret back as `createdKey`. The block shows it once with a copy button and a plain note that it
will not be shown again, and forgets it when `onCreatedKeyDismiss` clears the prop. Revoking asks
first, in a dialog that names the key.

## Logic

`apiKeyStatus`, `maskApiKey`, `apiKeyExpiryDate`, `apiKeyNameError` and `sortApiKeys` are exported
and tested on their own, so a server can check names the same way.

## Accessibility

- The new secret sits in a focusable element with a name, and copying is announced.
- Every revoke button and dialog names the key it acts on; after a revoke, focus moves to the next row, else the previous one, else the empty state action or the heading.
- Name errors are tied to the field and say what to write instead.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity and renders the plain block under reduced motion.
