## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add notification-preferences
```

The motion variant is `motion-notification-preferences`. It installs the plain block too.

## Usage

Pass the channels, the events (each with a group) and the current matrix: for each event id, the
channel ids it goes to. The block is controlled; `onChange` gets the whole new matrix, so save it as
it comes or behind your own button. An All events row under the channel names turns a whole column on or off and
shows a mixed state when only some are on. Channels listed in an event's `required` stay checked,
carry a lock and say why. On a narrow block each event becomes its own row of labelled boxes.

## Logic

`notificationOn`, `setNotification`, `notificationColumnState`, `setNotificationColumn`,
`groupNotificationEvents` and `notificationCount` are exported and tested on their own; none of them
ever turns a required channel off.

## Accessibility

- A real table with column, row and group headers; every box is named for its event and channel.
- Column boxes report a mixed state; locked boxes are described by the note that explains them.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant renders the plain block under reduced motion.
