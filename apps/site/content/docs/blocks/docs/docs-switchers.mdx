## Install

```sh
pnpm dlx @rectio/cli add docs-switchers
```

This block has no motion variant: nothing on it moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

Two menus for the header: one links to other versions of the docs and one to other languages. Each is a list of links, so the choice is a normal page load. Each language is named in its own tongue, so a reader finds theirs without reading the current one.

## Usage

Give each version a `value`, a `label` and an `href`, plus a `note` such as Latest or Legacy. Give each language a BCP 47 tag, its own name and the `href` of that translation. `current` is the `value` of what the reader is on. Put them in the `actions` of `DocsHeader`. Set `compact` on the language switcher to show only the globe in a narrow header.

## Accessibility

- The current version and language are marked with `aria-current`.
- Each language label carries its own `lang`, so it is pronounced correctly.
