## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add hero
```

The motion variant is `motion-hero`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

The first screen of a page: a headline, one sentence, one or two actions and your product rendered
live. Four layouts share the same copy props.

## Usage

Pick the layout by component: `HeroCentered`, `HeroSplit`, `HeroFloating` or `HeroWordCycle`. Wrap
words in `Em` to stress them. The `visual` is any node, ideally a real block in its real state.

## Accessibility

- Each hero is a section named by its headline.
- The cycling headline reserves the widest word's width so nothing moves, holds while hovered, settles after a few rounds and reads as one stable sentence to assistive technology.
- Under reduced motion the cycle holds still and the motion variants render the plain block.
- On narrow screens the floating cards line up under the visual instead of covering it, and a phone shows two.
