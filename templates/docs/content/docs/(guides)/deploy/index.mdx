A worker is a long-running process. Deploy it the way you deploy any service, and give it time to finish its jobs when it stops.

## Shut down gracefully

On `SIGTERM` a worker stops taking new jobs and waits for the running ones, up to `shutdownTimeout`. Jobs still running after that are released and retried by another worker.

```ts title="src/worker.ts" {5}
import { startWorker } from '@halyard/core';

const worker = await startWorker({
  queues: [emails, reports],
  shutdownTimeout: '30s',
});
```
