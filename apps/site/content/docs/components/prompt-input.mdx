## Install

```sh
pnpm dlx @rectio/cli add prompt-input
```

`file-upload` installs with it for attachments.

## Usage

```tsx
import { PromptInput } from '@/components/ui/prompt-input';

<PromptInput
  status={status}
  onSubmit={(text, attachments) => send(text, attachments)}
  onStop={stop}
  attachments={files}
  onAttach={upload}
  onRemoveAttachment={remove}
  maxLength={4000}
/>;
```

Enter sends and Shift Enter adds a line; on touch screens Enter adds a line and the Send button
sends, and `submitKey="mod-enter"` asks for Ctrl or Cmd. Typing in an input method never sends
mid word. The field empties and keeps focus after sending; return `false` from `onSubmit` to keep
the text. Send waits while the field is empty, a reply streams or a file is still uploading, and
turns into Stop while `status` is `streaming`. Near `maxLength` it counts the characters left.

## Props

Every prop of a `form` is accepted as well.

<TypeTable
  type={{

  }}
/>

## Accessibility

- The field is named Message; Send and Stop are named buttons that stay focusable while they wait.
- The count near the limit and upload waits are said politely.
- Touch targets reach 44px.
