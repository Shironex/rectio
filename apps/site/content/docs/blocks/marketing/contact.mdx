## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add contact
```

The motion variant is `motion-contact`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

A contact section: a heading and other ways to reach you on one side, a form on the other.

## Usage

The block sends nothing itself. Pass `onSubmit`: resolve when the message is on its way, or throw an
`Error` to show its message above the button. Leave out `topics` for no topic field, and pass
`consentLabel` to ask the sender to agree before sending.

## Logic

`validateContact(values, { needsTopic, needsConsent })` and `isEmail(value)` are exported, so a
server can run the same checks. `EMPTY_CONTACT` is the empty form.

## Accessibility

- Every error says what to fix, in words.
- The first invalid field takes focus on submit.
- The button holds its place while sending, and a sent message replaces the form in a polite live region.
