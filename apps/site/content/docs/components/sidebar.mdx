## Install

```sh
pnpm dlx @rectio/cli add sidebar
```

`kbd`, `menu`, `sheet`, `tooltip` and their dependencies install with it.

## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarHeader,
  SidebarInset,
  SidebarItem,
  SidebarProvider,
  SidebarSubItem,
  SidebarSubmenu,
  SidebarTrigger,
} from '@/components/ui/sidebar';

<SidebarProvider>
  <Sidebar label="Main">
    <SidebarHeader>Harbour &amp; Finch</SidebarHeader>
    <SidebarContent>
      <SidebarGroup label="Finance">
        <SidebarItem href="/overview" icon={<HouseIcon />}>
          Overview
        </SidebarItem>
        <SidebarSubmenu label="Receivables" icon={<ReceiptIcon />} active>
          <SidebarSubItem href="/invoices" active>
            Invoices
          </SidebarSubItem>
          <SidebarSubItem href="/customers">Customers</SidebarSubItem>
        </SidebarSubmenu>
        <SidebarItem href="/payables" icon={<BankIcon />} badge={4}>
          Payables
        </SidebarItem>
      </SidebarGroup>
    </SidebarContent>
  </Sidebar>
  <SidebarInset>
    <SidebarTrigger />
    {/* the page */}
  </SidebarInset>
</SidebarProvider>;
```

On desktop the sidebar is a full-height column that folds to an icon rail. In the rail the labels
become tooltips and accessible names, group headings become hairlines, and a submenu opens as a
flyout beside its icon, so nested pages stay one click away. Below the medium breakpoint the sidebar
is an off-canvas sheet from the start edge, opened by `SidebarTrigger`, and always shows labels.
Following a link in the sheet closes it.

`mod+b` folds and unfolds the sidebar from anywhere (Command B on a Mac, Control B elsewhere); it is
ignored while typing in a field, where it may mean bold. Pass `shortcut` to change it or `null` to
bind nothing. The fold is not animated on purpose, because it would animate the width and push the
page around. Save the choice with `onCollapsedChange` and start from it with `defaultCollapsed`.

Mark the item of the current page with `active`. An item with an `href` follows a
[`LinkProvider`](/docs/components/link), or pass `render` for a link of your own:
`render={<Link to="/invoices" />}`. Without `href` or `render`, an item is a button, for an action.

`useSidebar()` returns `collapsed`, `toggle()`, `mobile` and `mobileOpen` anywhere inside the
provider. The sidebar needs a `TooltipProvider` above it for the delay group; `AppShell` adds one.

### SidebarHeader, SidebarContent, SidebarFooter, SidebarInset

Plain `div` elements. The header holds the product mark, the content scrolls and holds the groups,
the footer holds the account menu or settings, and the inset is the column beside the sidebar.

## Accessibility

- The sidebar is a `nav` landmark named by `label`; groups are named by their heading.
- The current item carries `aria-current="page"`.
- The trigger reports `aria-expanded` and names its action ("Collapse sidebar", "Expand sidebar",
  "Open navigation"); its tooltip shows the shortcut.
- In the icon rail every item keeps its name for screen readers and gets a tooltip on hover and
  focus.
- The phone sheet is a modal dialog with focus trapped, restored on close, and closed by Escape.
