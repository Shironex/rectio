## Install

```sh
pnpm dlx rectio add tabs
```

## Usage

```tsx
import { Tabs, TabsList, TabsPanel, TabsTab } from '@/components/ui/tabs';

<Tabs defaultValue="open">
  <TabsList aria-label="Invoices by state">
    <TabsTab value="open" hint="12">
      Open
    </TabsTab>
    <TabsTab value="overdue" hint="3">
      Overdue
    </TabsTab>
  </TabsList>
  <TabsPanel value="open">{/* open invoices */}</TabsPanel>
  <TabsPanel value="overdue">{/* overdue invoices */}</TabsPanel>
</Tabs>;
```

`line` (the default) draws an underline under the active tab and suits sections of a page.
`segmented` draws a switch and suits a few views of the same thing, such as chart or table, or month
or quarter. On a phone the line variant scrolls sideways instead of wrapping, so the underline stays
on one line.

The indicator is placed from Base UI's measurements. In the plain tabs it jumps to the active tab;
the motion variant glides it on a spring, and falls back to the plain one under reduced motion. Use
`TabsList` and `TabsPanel` from `@rectio/motion/navigation` together with the plain `Tabs` and
`TabsTab`.

`tabsIndicator` is exported, and `indicator={false}` hides the built-in one, for a motioned
indicator of your own.

## Props

### Tabs, TabsPanel

Base UI's `Tabs.Root` and `Tabs.Panel`. `Tabs` takes `value`, `defaultValue`, `onValueChange` and
`orientation`; each `TabsPanel` takes the `value` of its tab. Panels are focusable.

### TabsList

Every prop of Base UI's `Tabs.List` is accepted as well.

## Accessibility

- Name the list with `aria-label`; each tab is tied to its panel.
- Arrow keys move between tabs, Home and End jump to the ends, and Tab moves from the list into the
  active panel.
- A disabled tab can take focus but does not open its panel.
- The active tab differs by weight and text colour as well as the indicator.
