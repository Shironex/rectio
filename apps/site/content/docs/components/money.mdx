## Install

```sh
pnpm dlx rectio add money
```

## Usage

```tsx
import { Money } from '@/components/ui/money';

<Money amount={-61} currency="EUR" locale="en-IE" tone="auto" />;
```

`Money` formats with `Intl.NumberFormat` and replaces the hyphen Intl returns with the true minus
sign (U+2212), which is as wide as a plus, so signed figures stay aligned. Figures are tabular and
lining, so a column of amounts lines up digit by digit.

It is neutral by default. `tone="auto"` colours a credit positive and a debit negative; the sign is
printed either way, so colour is never the only signal. `accounting` writes a debit in parentheses,
as ledgers do. `quietCurrency` dims the symbol so the figures lead.

For text such as a toast message, `formatMoney(amount, currency, options)` returns the same string,
and `formatMoneyParts` returns the parts.

The motion variant counts from the shown figure to the new one when the amount changes, waiting for
the change that caused it to land first. It is meant for totals. Screen readers read only the final
figure, and the count never overshoots.

## Accessibility

- The sign is always in the text, and `data-direction` (`credit`, `debit` or `zero`) is set for
  styling, so meaning never rests on colour.
- The figures use the theme's numeric face through the `--rx-money-family` token.
