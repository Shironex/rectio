## Install

```sh
pnpm dlx @rectio/cli add heatmap
```

## Usage

```tsx
import { Heatmap } from '@/components/ui/heatmap';
import { localDate } from '@/lib/local-date';

// A year of days: weekdays down, weeks across.
<Heatmap variant="calendar" data={[{ date: localDate('2026-03-02'), value: 4 }]} label="Deploys" />;

// Two categories: rows by columns.
<Heatmap
  rows={[{ id: 'jun', label: 'Jun 2026' }]}
  columns={[
    { id: 'm0', label: 'Month 0' },
    { id: 'm1', label: 'Month 1' },
  ]}
  data={[
    { row: 'jun', column: 'm0', value: 1 },
    { row: 'jun', column: 'm1', value: 0.71 },
  ]}
  format="percent"
  rowHeader="Cohort"
/>;
```

Figures above zero fall into even steps of the warm sequence tokens, palest to deepest, up to the
largest figure (or `max`). Zero has its own quiet cell, and a cell with no figure (`null`) is hatched,
so missing and zero never look alike. The legend shows the zero cell, the steps up to the largest
figure, and No data when any cell is missing.

`calendar` builds the weeks from local dates, so a daylight saving change never shifts a day. The range runs from the earliest entry to the latest: days in it
with no entry are missing, and days outside it get no cell. Months are labelled over the week that
holds the 1st, and `weekStartsOn` (Monday by default) sets the first row. Cells stay between 10 and 22
pixels: on a phone a year scrolls sideways, opened at the latest week, and on a wide screen it stops
growing. A matrix prints each figure in its cell, in a text token that holds 4.5:1 on every step;
its columns keep room for a figure, so on a phone it scrolls sideways too. While more columns wait
past the edge, a fade says so, and the row labels stay in view.

The motion variant uncovers the grid on first view.

`heatStep(value, max, steps)` gives the step of a figure: 0 for zero and below, then 1 to `steps`.

## Accessibility

- A read-only grid with row and column headers. One cell is in the tab order; the arrow keys move
  between cells with figures, Home and End go to the ends of a row, and with Ctrl to the first and
  last cell.
- Every cell's name holds its row, column (or date) and figure, so nothing is read from colour.
- A summary says how many cells there are, the highest and how many are missing, then the scale;
  the table twin lists every figure.
- Missing cells are hatched as well as tinted, and zero has an outlined cell of its own.
