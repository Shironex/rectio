## Install

```sh
pnpm dlx @rectio/cli add budget-vs-actual
```

The motion variant is `motion-budget-vs-actual`. It installs the plain block too and changes only how the
block enters.

## Usage

Each bar is drawn against its own budget: the outline is 100% of budget and spend past it runs
on in the second series colour. The variance is signed as actual minus budget (plus is over),
with an arrow and the word over or under; colour adds whether that is good news for `kind`. A line
within half a percent reads as on budget.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source is in
the repository, under `packages/blocks`.

## Messages

Every word the block prints, including what screen readers hear, comes from `messages`. The full
English defaults are exported as `BUDGET_VS_ACTUAL_MESSAGES`, typed as `BudgetVsActualMessages`. Pass only the keys you
change; a message that counts or names a figure is a small function, so a language can order the
words and choose its plural form with `plural()`.

```tsx
<BudgetVsActual
  lines={lines}
  currency="GBP"
  locale="en-GB"
  messages={{
    title: 'Budget and actuals',
    onBudget: 'On plan',
    varianceWords: (position, percent) =>
      `${percent ?? ''} ${position === 'over' ? 'above plan' : 'below plan'}`.trim(),
  }}
/>
```

A complete set typed as `BudgetVsActualMessages` fails to compile when a key is missing.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`variance(line, kind, currency)` and `budgetSummary(lines, kind, currency)`.

## Accessibility

- Variance never rests on colour: the sign, the arrow and the words all agree.
- The bars are decorative; budget, actual and variance are all in the table.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
