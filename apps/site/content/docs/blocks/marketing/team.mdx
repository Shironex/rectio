## Install

```sh
pnpm dlx @rectio/cli add team
```

The motion variant is `motion-team`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

An about section: who the team is, what it works by, and the people, each with their role and a line
on what they do.

## Usage

Values are a short ruled list before the people. A member without an `avatar` shows their initials
on a soft tint, so no photos are needed. Member links read with the person's name for screen
readers.

## Accessibility

- The people are a list labelled "Team"; values are a description list.
- Each link is named with its person, such as "Profile, Ada Lindqvist".
