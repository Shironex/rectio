## Install

```sh
pnpm dlx @rectio/cli add notifications-center
```

The motion variant is `motion-notifications-center`. It installs the plain block too; notifications leave the Unread list in place.

## Usage

Put the block in your app header: it draws the bell with the unread count, and opens the list in a
popover anchored to it. Pressing a notification marks it read (`onMarkRead`) and calls `onOpen`, so
you can navigate to it. Read state stays in your app; `markNotificationRead` and
`markAllNotificationsRead` update a list kept in state.

With `inline` the same list sits on the page as a panel, for a notifications page or a sidebar.

## Logic

`unreadNotificationCount`, `visibleNotifications`, `markNotificationRead`,
`markAllNotificationsRead` and `unreadBadgeText` are exported and tested on their own.

## Accessibility

- The bell is named with the unread count; the badge on it is decoration.
- Unread notifications say so in words as well as with the dot; the count is announced as it changes.
- The popover moves focus inside on open, and Escape returns it to the bell.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
