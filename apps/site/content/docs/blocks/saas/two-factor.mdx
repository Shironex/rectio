## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add two-factor
```

The motion variant is `motion-two-factor`. It installs the plain block too and changes only how the
block enters.

## Usage

Show the block after the password step. It calls `onVerify` as soon as the last digit lands (or on
Verify), with `remember` when the person ticked your `rememberLabel`. Your server checks the code;
pass `pending` while it does and a refusal as `error`, which is tied to the code field.

For text and email codes, `onResend` adds a resend button that waits out `resendCooldown` seconds
from `sentAt`. `onUseBackupCode` adds a second view for a saved backup code, cleaned of spaces and
hyphens before it reaches you.

## Logic

`twoFactorCodeComplete`, `twoFactorResendWait`, `formatTwoFactorWait`, `normalizeBackupCode`,
`backupCodeError`, `maskTwoFactorDestination` and `twoFactorInstruction` are exported and tested.

## Accessibility

- The first slot carries the field label and `autocomplete="one-time-code"`, so a code from a text message fills every slot; the others name their position.
- Pasting a whole code into any slot fills them all.
- The resend button says how long is left in words, and wakes up by itself.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
