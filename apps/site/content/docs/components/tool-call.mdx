## Install

```sh
pnpm dlx @rectio/cli add tool-call
```

## Usage

```tsx
import { ToolCall } from '@/components/ui/tool-call';

<ToolCall
  name="search_invoices"
  title="Searched unpaid invoices"
  status="done"
  duration="0.8 s"
  args={{ status: 'unpaid' }}
  result={{ count: 3 }}
/>;
```

A quiet row with the status in an icon and a word, what the tool did and how long it took. Open, it
shows the arguments and result as formatted JSON, or `result` as any element you render, such as a
table. A failed call shows its `error`.

## Accessibility

- A disclosure button with `aria-expanded`; status is in words as well as the icon.
- The data blocks are focusable, so long JSON scrolls from the keyboard.
