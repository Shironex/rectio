The marketing blocks are the sections of a product site, built only from rectio components and
tokens: the header and footer, heroes, features, logos, figures, testimonials, FAQ, a closing
call to action, a newsletter signup, a team page, a contact form, a blog, legal pages and a cookie
banner.

## Plain and motion twins

Every block that has something to animate has a motion twin with the same name and props. Pick per
block by import path:

```tsx
import { HeroCentered } from '@rectio/blocks/marketing'; // plain
import { HeroCentered } from '@rectio/blocks/marketing/motion'; // enters once, on first view
```

In the motion variants sections fade up once on first view, stats count to their figure and a
cycling headline slides its words. Reduced motion renders the plain block. The header, footer,
legal page and announcement bar have nothing to animate, so they have no twin; the motion path
exports them unchanged, so a page can import every block from one place.

## Server and client components

The static blocks are server components, so a React Server Component page can render them with no
client JavaScript of their own. The interactive ones (contact, newsletter, cookie consent, site header,
legal and the word-cycle hero) and every motion twin are client components. React does not let a
server component pass event handlers down, so props such as the announcement bar's `onDismiss` need a
client parent.

## Content is data

Every headline, link, list and quote is a prop. Blocks never fetch, never send and hold no list:
a form takes an `onSubmit` or `onSubscribe` callback and you decide where the message goes. Links
are plain `{ label, href }` records, and a call to action is a link drawn as a button.

## One place for links

Every link in every block renders through the kit's [`Anchor`](/docs/components/link). Wrap your
app in `LinkProvider` with your router's link component and every block follows it and its base
path, with no prefix in your link data.

## Small internal pieces

The blocks carry their own small Accordion, Avatar, Switch and Textarea, so installing a marketing
block does not pull extra components into your project. A shared `marketing-core` item (sections,
headings, links drawn as buttons, the marquee and prose styles) comes with the first block you add.

## Legal text and consent

The legal page ships templates for a privacy policy, terms of service and cookie policy. They are
placeholders: replace with your own legal text. This is not legal advice. The cookie banner records
a visitor's decision and gives you the data to act on; making your site compliant, and keeping the
cookie list true, is your job.
