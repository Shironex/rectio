## Install

```sh
pnpm dlx rectio add payouts
```

The motion variant is `motion-payouts`. It installs the plain block too and changes only how the
block enters and how rows leave a filtered view.

## Usage

A payout is scheduled, in transit, paid, failed or cancelled; its date means what the status means
(leaves, arrives, arrived, failed, cancelled). Failed payouts lead the list with the bank's reason
and a Retry; then what is on its way and scheduled, soonest first; then history, newest first.

The figures read: scheduled in the next `horizonDays`, in transit, paid since `paidSince` (the first
of the month by default) and failed, emphasised when there is any. The footer sums the payouts
shown, leaving failed and cancelled ones out.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. Pass the
ids being retried as `retrying` and their Retry shows a spinner and ignores presses.

## Messages

Every word the block prints, including what screen readers hear, comes from `messages`. The full
English defaults are exported as `PAYOUTS_MESSAGES`, typed as `PayoutsMessages`, including a word
for each payment method. Pass only the keys you change; a message that counts or names a figure is
a small function, so a language can order the words and choose its plural form with `plural()`.

```tsx
import { plural } from '@rectio/blocks';

<Payouts
  payouts={payouts}
  currency="PLN"
  locale="pl-PL"
  messages={{
    title: 'Wypłaty',
    retry: 'Ponów',
    payoutCount: (count) =>
      `${count} ${plural(count, { one: 'wypłata', few: 'wypłaty', many: 'wypłat', other: 'wypłaty' }, 'pl-PL')}`,
  }}
/>;
```

A complete set typed as `PayoutsMessages` fails to compile when a key is missing.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`payoutTotals(payouts, today, currency, { horizonDays, paidSince })`, `nextPayout(payouts, today)`
and `sortPayouts(payouts)`.

## Accessibility

- Every status is a badge with a word and an icon, never colour alone; a failure carries the bank's reason in words.
- Retry names the payee and the amount for screen readers, and announces when it is busy.
- The status filter is one toggle group: arrow keys move between options and the pressed one is announced.
- Every figure is in tabular numerals; a cancelled amount is struck through and left out of the total.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
