---
title: Blocks
description: 'Finance screens composed from rectio components, ready to adapt.'
---

Blocks are whole pieces of a finance screen, built only from rectio components and tokens: the
kind of composition every expense, ledger or approval tool ends up writing by hand.

Each block is data-agnostic: typed props in, callbacks out, no fetching. Its money logic (totals,
VAT, running balances, aging, variance, approval moves) is exported and tested on its own, and
every sum runs in minor units. Each block has a motion variant with the same props, picked by
import path:

```tsx
import { InvoiceList } from '@rectio/blocks'; // plain
import { InvoiceList } from '@rectio/blocks/motion'; // enters once, on first view
```

| Block                                                   | What it answers                   |
| ------------------------------------------------------- | --------------------------------- |

| [Invoice detail](/docs/blocks/invoice-detail)           | What does this invoice come to?   |

Blocks are built only from rectio components and tokens, so they follow the theme, mode and
density of their scope, and install the free components they render.
