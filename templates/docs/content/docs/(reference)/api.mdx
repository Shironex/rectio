Everything is exported from `@halyard/core`. Types are inferred from your queue definitions, so you rarely write them by hand.

## Queues

A queue holds one kind of job. Define it once and import it wherever jobs are added or run.

<SignatureCard
  name="defineQueue"
  kind="function"
  signature="defineQueue<Job, Result>(name: string, options: QueueOptions<Job, Result>): Queue<Job, Result>"
  description="Creates a queue. The type of the job is taken from the run function's parameter."
  params={[
    {
      name: 'name',
      type: 'string',
      description: 'Unique across the store. Used in keys, the dashboard and events.',
    },
    {
      name: 'options',
      type: 'QueueOptions<Job, Result>',
      description: "The run function and the queue's own policies.",
    },
  ]}
  returns={{ type: 'Queue<Job, Result>', description: 'The queue, to add jobs to and listen on.' }}
  since="2.0.0"
/>

## Workers

A worker takes jobs from its queues and runs them. Run it in its own process so a busy queue never slows your server.

<SignatureCard
  name="startWorker"
  kind="function"
  signature="startWorker(options: WorkerOptions): Promise<Worker>"
  description="Connects to the store and runs jobs from the given queues until it is stopped."
  params={[
    { name: 'queues', type: 'Queue[]', description: 'The queues this worker takes jobs from.' },
    {
      name: 'concurrency',
      type: 'number',
      description: 'Jobs run at the same time. Defaults to config.concurrency.',
    },
    {
      name: 'shutdownTimeout',
      type: 'Duration',
      description: 'How long to wait for running jobs on SIGTERM. Default 30s.',
    },
  ]}
  returns={{ type: 'Promise<Worker>', description: 'The worker, with stop() and its own events.' }}
/>
