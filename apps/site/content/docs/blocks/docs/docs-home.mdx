## Install

```sh
pnpm dlx @rectio/cli add docs-home
```

The motion variant is `motion-docs-home`. It installs the plain block too and changes only how the block moves.

The docs blocks share a small core (`docs-core`) that `add` installs for you.

The front page of the docs: a hero with a title, a line of description, two ways in and a one-line command to copy, then link cards for the main routes or a compact list for many smaller ones. In the motion variant both fade up once on first view.

## Usage

Use `primary` and `secondary` for the two ways in, and `install` for a command with a copy button. `aside` is the right column: a code sample, install tabs or a screenshot. `LinkCards` takes `{ title, description, href, icon, badge }` records; use `variant="list"` for many secondary links in less space, and `columns` to choose two or three. Set `wide` on `DocsLayout` for this page.
