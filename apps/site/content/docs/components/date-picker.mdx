## Install

```sh
pnpm dlx @rectio/cli add date-picker
```

`calendar`, `field`, `select` and `theme-scope` install with it, and `date-fns` is added to your
`package.json`.

## Usage

### DatePicker

```tsx
import { DatePicker } from '@/components/ui/date-picker';
import { Field, FieldLabel } from '@/components/ui/field';

<Field>
  <FieldLabel>Invoice date</FieldLabel>
  <DatePicker locale="en-IE" value={date} onValueChange={setDate} />
</Field>;
```

Type the date in the locale's short pattern (`dd/mm/yyyy` for `en-IE`), or open the calendar with
the button or Alt and Arrow Down. A typed date is read on blur or Enter and rewritten in the locale
format. Text that is not a date reports `null` and stays in the field to be fixed. Pressing the
chosen day again keeps it; it never empties the field.

`displayFormat` sets how the field shows the date: a date-fns pattern such as `'d MMM yyyy'`
(5 Mar 2026), `'PP'` for the locale's medium date, or a function. The field reads its own pattern
and the locale's short one, so typing `5/3/2026` still works in a field that shows `5 Mar 2026`.

`datePattern(dateLocale)`, `parseDate(text, dateLocale, displayFormat?)` and
`formatDisplayDate(date, dateLocale, displayFormat?)` are exported for your own validation
messages, such as "Enter the date as dd/mm/yyyy."

### DateRangePicker

```tsx
import { DateRangePicker, type DateRange } from '@/components/ui/date-picker';

<DateRangePicker
  aria-label="Statement period"
  locale="en-IE"
  value={period}
  onValueChange={setPeriod}
  presets={[{ label: 'March', range: { from: new Date(2026, 2, 1), to: new Date(2026, 2, 31) } }]}
/>;
```

A button that shows the period and opens two months. Each opening picks a fresh period: the first
press sets the start, the second the end, then it closes. Closing early keeps the start. Presets sit
beside the calendar with their dates written out; one press picks the whole period.

### RangeCalendar

<Preview name="range-calendar" plain={<Demo name="range-calendar" />} />

```tsx
import { RangeCalendar } from '@/components/ui/date-picker';

<RangeCalendar
  aria-label="Report period"
  value={period}
  onValueChange={setPeriod}
  presets={presets}
/>;
```

The same two months and presets in place, for a filter panel or a page of its own. While the end
is open, the days up to the pointer are shaded, and a line under the months says what is picked:
"Pick the first day", then "From 12 Mar 2026. Pick the last day", then "12 Mar to 18 Mar 2026, 7
days". `formatDateRange` and `rangeLength` are exported for your own summaries.

Both popups portal into the nearest `ThemeScope`. On phones the calendar opens as a sheet along the
bottom edge, with its own close button.

## Accessibility

- The input is named by its `FieldLabel` and shows the locale pattern as its placeholder.
- The calendar button is named "Choose date", plus the chosen date when there is one.
- The calendar opens on the chosen day with focus on it, and picks from the keyboard like
  [Calendar](/docs/components/calendar).
- The range calendar's summary is a polite live region, so each press is read out.
- The range button's name includes the period it shows. The preset matching the current period is
  marked pressed (`aria-pressed`), and each preset reads its dates.
