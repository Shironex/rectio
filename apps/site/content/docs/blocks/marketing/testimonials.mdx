## Install

```sh
pnpm dlx @rectio/cli add testimonials
```

The motion variant is `motion-testimonials`. It installs the plain block too and changes only how the
block enters.

The marketing blocks share a small core (`marketing-core`) that `add` installs for you.

What customers say, in three shapes: one large quote with an optional result beside it, an even
grid, or a wall of quotes drifting in two rows.

## Usage

Write the quote without quotation marks: the block adds them. Three lines at most reads best. With
no `avatar`, the person's initials show. In the grid the first quote is set larger as the lead, and
with an odd count it spans two rows so the grid closes without a gap. Pair the marquee with a
static logo strip: one moving strip per page.

## Accessibility

- Each quote is a figure with its author named beside it.
- The marquee stops on hover and focus, has a pause button, and under reduced motion the quotes simply wrap.
- A photo is named with the person's name; initials are hidden from assistive technology because the name is beside them.
