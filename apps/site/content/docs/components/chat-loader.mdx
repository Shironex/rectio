## Install

```sh
pnpm dlx @rectio/cli add chat-loader
```

## Usage

```tsx
import { ChatLoader } from '@/components/ui/chat-loader';

<ChatLoader />;
<ChatLoader variant="skeleton" lines={4} label="Loading history" />;
```

The motion variant fades the dots up into the reply's place.

## Props

<TypeTable

  }}

## Accessibility

- A `status` with its label in words. Under reduced motion the dots breathe instead of bouncing.
