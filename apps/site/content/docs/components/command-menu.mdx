## Install

```sh
pnpm dlx rectio add command-menu
```

`kbd` and `theme-scope` install with it.

## Usage

```tsx
import { CommandMenu, CommandMenuTrigger, type CommandGroup } from '@/components/ui/command-menu';

const groups: CommandGroup[] = [
  {
    label: 'Go to',
    items: [
      { id: 'payables', label: 'Payables', keywords: ['bills'], onSelect: () => go('/payables') },
    ],
  },
  {
    label: 'Actions',
    items: [
      { id: 'new-invoice', label: 'New invoice', shortcut: 'mod+shift+i', onSelect: newInvoice },
    ],
  },
];

<CommandMenu groups={groups}>
  <CommandMenuTrigger>Search pages and actions</CommandMenuTrigger>
</CommandMenu>;
```

The menu opens from anywhere on the page with `mod+k` (Command K on a Mac, Control K elsewhere);
pass `shortcut` to change it or `null` to bind nothing. Typing filters the items by fuzzy match
against the label and its `keywords`, so `nwinv` finds "New invoice", and the matched letters are
marked. The first result is highlighted, Arrow Up and Arrow Down move, Enter runs it and Escape
closes. The query is cleared on close.

`onSelect` runs after the menu closes. An item's `shortcut` is shown as keycaps but not bound: the
app binds it, as with `Menu`.

`CommandMenuTrigger` is a field-shaped button with the shortcut, for the header of an app. It shrinks
to the search icon on a phone. Give it the same `shortcut` as the menu. You can also control the menu
with `open` and `onOpenChange` and open it from any button.

Use `emptyState` to say something more useful than the default when nothing matches. `filterCommands` and
`fuzzyScore` are exported if you want to reuse the matching.

The command menu has no open animation, and no motion variant, on purpose. It is used dozens of times
a day, and the field should be ready the moment the shortcut is pressed.

## Accessibility

- Opens as a modal dialog named by `label`, with the search field focused. Escape closes it and
  returns focus to where it was.
- The field and the list work as a combobox: focus stays in the field while Arrow Up and Arrow Down
  move the highlighted item, and Enter runs it.
- Groups are named, items with a shortcut carry `aria-keyshortcuts`, and the keyboard hints are
  linked to the field as its description.
- With no matches the empty message is announced.
