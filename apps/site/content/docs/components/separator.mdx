## Install

```sh
pnpm dlx rectio add separator
```

## Usage

```tsx
import { Separator } from '@/components/ui/separator';

<Separator />;
<Separator label="or" />;
<Separator orientation="vertical" />;
```

Horizontal by default. A vertical separator stretches to the height of its row. `label` puts words
in the middle of a horizontal rule; `tone="strong"` holds its own against busy content.

## Props

Every prop of Base UI's `Separator` is accepted as well.

## Accessibility

- A separator with its orientation. With a label, the label is read and the two rules stay separators.
