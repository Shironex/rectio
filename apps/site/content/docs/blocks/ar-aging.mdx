## Install

Blocks are part of rectio Pro: set `RECTIO_LICENSE_KEY` first. Without a key, `add` refuses and
writes nothing.

```sh
pnpm dlx rectio add ar-aging
```

The motion variant is `motion-ar-aging`. It installs the plain block too and changes only how the
block enters.

## Usage

Buckets are current, 1 to 30, 31 to 60, 61 to 90 and over 90 days past due; due today is still
current. Each bar carries its amount as a label, so the deepening colour of older buckets only
reinforces what the words say.

The block is data-agnostic: it takes plain records and calls you back; it never fetches. The Code
tab shows the preview's usage. The block's own source comes with the license.

## Logic

The money logic is exported and tested on its own, so a server can compute the same figures:
`agingBucket(due, today)` and `agingReport(receivables, today, currency)`.

## Accessibility

- The chart has a table of the same figures, with each bucket's share.
- Bucket columns in the customer table name their range in full for screen readers.
- Every figure is in tabular numerals with a true minus sign; negatives carry the sign as well as colour.
- Works in both themes, light and dark, at compact density and down to phone width with 44px touch targets.
- The motion variant moves only transform and opacity, plays once on first view and renders the plain block under reduced motion.
