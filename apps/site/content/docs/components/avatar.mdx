## Install

```sh
pnpm dlx rectio add avatar
```

## Usage

```tsx
import { Avatar } from '@/components/ui/avatar';

<Avatar name="Ana Ruiz" src="/people/ana.jpg" status="online" />;
<Avatar name="Treasury" square size="lg" />;
```

Without a photo, or while it loads, the avatar shows the initials on one of six identity tints. The
tint comes from the name, so a person keeps the same colour in every list and on every screen. The
tints are tokens (`identity-1` to `identity-6`, a subtle fill and a strong text each), checked for
contrast in every theme and mode.

Status differs in shape as well as colour: online is solid, away has a hollow centre, busy carries a
bar, offline is an outline. Use `square` for teams, companies and anything that is not a person.

## Accessibility

- One image named by the person and the status: "Lena Fischer, busy".
- The photo has empty alt text and the initials are hidden, so nothing is read twice.
- The status is never colour alone: the dot changes shape and the words are in the name.
