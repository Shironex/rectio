## Install

```sh
pnpm dlx @rectio/cli add toggle
```

## Usage

```tsx
import { Toggle, ToggleGroup } from '@/components/ui/toggle';

<ToggleGroup legend="Period" value={period} onValueChange={setPeriod}>
  <Toggle value="week">Week</Toggle>
  <Toggle value="month">Month</Toggle>
  <Toggle value="quarter">Quarter</Toggle>
</ToggleGroup>;

<ToggleGroup aria-label="View" defaultValue={['list']} size="sm">
  <Toggle value="list" iconOnly aria-label="List">
    <ListIcon aria-hidden />
  </Toggle>
  <Toggle value="board" iconOnly aria-label="Board">
    <SquaresFourIcon aria-hidden />
  </Toggle>
</ToggleGroup>;

<Toggle pressed={archived} onPressedChange={setArchived}>
  Show archived
</Toggle>;
```

### Segmented control

```tsx
import { SegmentedControl } from '@/components/ui/toggle';

const STATUSES = [
  { value: 'all', label: 'All', hint: 48 },
  { value: 'unpaid', label: 'Unpaid', hint: 11 },
  { value: 'overdue', label: 'Overdue', hint: 3 },
  { value: 'paid', label: 'Paid' },
] as const;

<SegmentedControl label="Status" options={STATUSES} value={status} onValueChange={setStatus} />;
```

`SegmentedControl` is the group with single selection, driven by a list of options and one value
instead of toggles and an array. It always keeps one option chosen. An option can carry a `hint`,
such as a count, read after its label. By default the options sit in one row while they fit and
in two even columns on a phone or in a narrow container, so every label stays whole; set
`layout="row"` for two or three short options that always fit.

A toggle is a button that stays down: a view option or a filter that applies at once. A
`ToggleGroup` draws its toggles as one segmented control and sets their size.

The group picks one toggle by default, and keeps one picked: pressing the chosen toggle again does
nothing. Set `allowEmpty` to let it clear, or `multiple` for independent filters such as Open,
Overdue and Paid. The value is always an array of toggle values, also with single selection.

Name the group with a visible `legend` or with `aria-label`. For a choice that is part of a form
and needs a description or an error, use a `RadioGroup`.

The motion variant of `ToggleGroup` slides one raised chip to the chosen segment. Only a group
with single selection glides; with `multiple` it is the plain group.

## Props

### Toggle

Every prop of Base UI's `Toggle` is accepted as well: `pressed`, `defaultPressed`,
`onPressedChange`, `value`, `disabled` and the rest.

`allowEmpty`, which it replaces.

## Accessibility

- Each toggle is a button with `aria-pressed`. Space and Enter press it.
- In a group, the arrow keys move between toggles and Tab leaves the group.
- A pressed toggle shows a raised chip in a group, or a filled surface with an edge alone, as well
  as the stronger text colour.
- Icon only toggles need an `aria-label`.
- A group grows to 44px on touch screens, and each segment is at least 44px wide. A toggle alone, of
  any size, reaches 44 by 44 through its hit area, so a one-letter label still makes the width.
