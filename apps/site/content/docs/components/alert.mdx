## Install

```sh
pnpm dlx @rectio/cli add alert
```

## Usage

```tsx
import { Alert } from '@/components/ui/alert';
import { Button } from '@/components/ui/button';

<Alert tone="warning" title="Bank feed paused" actions={<Button size="sm">Reconnect</Button>}>
  Transactions after 12 March are not imported.
</Alert>;
```

Pick the tone by meaning: `danger` for a failure that blocks, `warning` for a risk, `success` when
something is done, `info` for news, `neutral` for a quiet callout. The icon and the title say the
tone, so the alert reads without colour; the whole box carries the tint, never a stripe down one side.
`variant="outline"` sets the alert on the surface with only the icon tinted, for a callout inside a
panel.

An alert that is part of the page from the start stays silent. One that appears after something
happened should announce itself: `live="assertive"` for an error, `live="polite"` for news.

The motion variant lifts away when dismissed instead of vanishing, and rises in when it arrives live.

## Accessibility

- Silent by default; `live` makes it a status or an alert that is announced on arrival.
- The tone icon is decorative; the title carries the meaning.
- The dismiss button is named and reachable from the keyboard, with a 44 pixel target on touch screens.
